# aap-parenting-encyclopedia

WorkBuddy Skill：把《美国儿科学会育儿百科（第7版）》转换为结构化、可检索的育儿知识库。

> **本仓库为私有（Private）。** 内容是对受版权保护的中文译本的摘录式结构化整理，仅供个人学习与自用，**不得公开转载、分发或用于任何商业用途**。详见文末「版权与使用限制」。

## 这是什么

一本 13,004 字（约 39.7 万 tokens）的育儿百科，被拆成「一页速查 + 10 个思维模式 + 35 个章节文件 + 术语表」四层结构，让 AI 助手能在回答育儿问题时**直接命中阈值和红线**，而不是输出一堆"可能"。

设计目标不是"复述书"，而是保留原书的**判断链**：

- 每个阈值都带月龄前提（年龄是第一变量）
- 每条"要不要就医"都给出可数的红线条目
- 每个模糊地带都给出**观察窗**（24 小时 / 3–5 天 / 6 周）
- 每个流行误解都给出**明确结论**（有关联 / 无关联 / 无效 / 有害）

## 核心框架（11 条）

1. **年龄是第一变量**——所有阈值随月龄变化
2. **三层分诊**：现在（分钟–小时）/ 尽快（24–72 小时）/ 观察
3. **时序鉴别**：谁先谁后就是诊断（先腹痛后呕吐→外科；热退出疹→幼儿急疹）
4. **红线清单优于可能性清单**
5. **观测窗**：用时间代替判断（跛行 24 小时 / JIA ≥6 周）
6. **时机优先于方法**（睡眠：早开始、一致、坚持）
7. **环境先于说教**（因果缺口原则）
8. **反向减法**：先停什么，再谈加什么
9. **循证否定**：给结论，不给"科学证明"
10. **儿童剂量放大原理**：比相对剂量，不比绝对暴露量
11. **关键数量级锚点**（Hib 2 万例/年 → <100 例/年 等）

## 怎么用

把本目录放到 WorkBuddy 的 skills 目录下：

```
~/.workbuddy/skills/aap-parenting-encyclopedia/
```

新开会话后，Skill 列表会自动加载。之后可以直接问：

- 「发烧 38.5 要不要去医院」→ 命中年龄阈值表
- 「2 岁还不会说句子正常吗」→ 命中 ch11 语言筛查线
- 「打完疫苗会得自闭症吗」→ 命中 ch31 循证否定
- 「孩子抽搐了怎么办」→ 命中 ch23 急症处理
- 「怎么判断严重程度」→ 命中 patterns.md 分诊三分法

也可以手动指定读哪个文件：`cheatsheet.md` 用于快速查数，`chapters/chNN-*.md` 用于完整解释。

## 已知限制

- **263 张源图片未提取**。皮疹形态、胎记外观、发育姿势示范等内容仅有文字描述，实际比对需查原书。
- **疫苗程序以美国 CDC/AAP 体系为准**。国内免疫规划不同，涉及具体接种时间表须另行核对。
- **不提供个体化诊断与药物剂量计算**。只给"何时就医 + 就医前做什么"，以及"禁用什么"。
- **版本**：原书为第 7 版，第 8 版之后的指南更新未反映。
- **一处书内勘误**（已在 ch34 标注）：原文「幼儿急疹」段落称病原为"细小病毒 B19"，与「第五病」段落重复，应为译/编误。

# 第12章 3岁

## Core Idea
3岁完成了从"幼儿"到"学龄前儿童"的转换：语言成为主要工具（替代抓人打人）、开始真正与他人合作游戏、开始有"公平"概念并会讨价还价。这一年的核心任务是**用语言自我调节 + 学会轮流与让步**。

## Frameworks Introduced
- **单向思维（Single-Angle Thinking）及其教育含义**：
  - 经典演示：两杯等量的水，一杯倒入矮胖杯、一杯倒入高瘦杯——3岁孩子坚持认为高瘦杯里更多，即使他亲眼看着水倒过去。
  - 原因：他认为"容器越高越大，水就越多"，只能从一个维度看问题。
  - 结论：**7岁左右才能多角度推理**，所以讲道理要短、要具体，别指望他理解多个条件叠加的规则。
- **口吃干预三不原则**：
  - 不纠正、不打断、不替他说完；
  - 全家放慢语速（身教优于"你慢点说"）；
  - 不流露厌恶/丢脸/无奈（禁用"慢点说！""重说一遍！""放轻松！"）。
  - 判据：偶尔重复音节、词、短语，或说话前停顿犹豫，属正常；**持续超过3个月且影响交流**才算真口吃。
- **道歉的两步前提**：先让他真正明白"错在哪"（通常4岁才具备这个理解力），再要求道歉；只教"对不起"三个字无法改变行为。
- **冲突调解四步**：确保不伤人 → 带离现场 → 聊想法搞清为何激动 → 引导换位思考（"别人打你你会怎样"）+ 一起想和平方案。

## Key Concepts
- **生长**：3岁这年身高＋约8.9厘米、体重＋约2.3千克；到5岁那一年降到＋6.4厘米、＋2千克。**每年测2次**并标在生长曲线上。
- **超重与停滞信号**：体重增幅超过身高增幅 → 超重风险；身高半年无变化 → 可能发育问题。两者都要找医生。
- **词汇**：3岁应达300个以上，能说3～4词句，陌生人能听懂约75%。
- **语言清晰度**：b/p/m/w/h 约3.5岁才掌握；ch→q、sh→x 等替换常见。
- **性别认同**：通过同性伙伴交往逐步建立，需数年；不给玩具按性别设限。
- **时间概念**：清楚日常作息，能记住年龄，但不懂"一年有多长"。

## Mental Models
- **"讨价还价是公平感的诞生"**：他说"我为你做这个，你为我做那个"让人恼火，但这是独立意识 + 公平概念的正常产物。
- **"角色扮演是最好的社交训练"**：分配角色、轮流、关注他人、回应他人——都在游戏中完成，比课堂有效。它同时锻炼执行功能（解决问题能力）。
- **"身教 > 言传"在这里最明显**：你暴躁，他就学会用暴怒应对压力；你冷静协商，他就学会协商。
- **"他把你当独立个体了"**：3岁开始能理解你也有情绪和需要，会安慰你——这是关系质变的信号。

## Anti-patterns
- **纠正孩子的代词用法**（他说"宝宝要"而非"我要"）：会让他更混乱，因为他以为你在说你自己。正确做法是自己始终用对（说"我想让你一起来"，而不是"爸爸想让你一起来"）。
- **强迫孩子为"不存在的错误"道歉**：先建立理解，再要求道歉。
- **把"话痨"当问题压制**：这是他积累词汇的主渠道。
- **用"慢点说"催口吃的孩子**：会加重焦虑与口吃。
- **因孩子瘦而加餐**：3岁后身高增速与体重/肌肉增速不同步，看起来瘦弱不代表不健康。

## Worked Example
一位家长处理3岁孩子抢玩具的全过程：

| 阶段 | 动作 |
|---|---|
| 现场 | 立即分开，确认无人受伤 |
| 命名 | "你想要那辆车，他先拿了，你很着急。" |
| 规则 | "我们可以轮流。你想先等，还是先玩这个？" |
| 换位 | "他抢你的车，你会怎么想？" |
| 收尾 | 等他真正明白（不是立刻）再道歉；表扬他"刚才你等了，这很难" |

若他持续出现社交退缩 + 兴趣狭窄 + 重复动作 → 转介孤独症谱系障碍专科评估（越早干预，对发育的整体影响越小）。

## Key Takeaways
1. 3岁词汇300+、3～4词句、陌生人听懂75%是语言底线；不达标要评估。
2. 口吃多为阶段性，三不原则（不纠正/不打断/不替说完）+ 全家放慢语速；超3个月且影响交流才需治疗。
3. 单向思维要到7岁才改善——讲道理必须短、具体、单一条件。
4. 每年测2次身高体重：体重增幅＞身高增幅=超重风险，身高半年不动=需就医。
5. 冲突处理顺序：安全 → 带离 → 聊原因 → 换位 → 真理解后再道歉。

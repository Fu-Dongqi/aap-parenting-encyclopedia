# 第19章 胸部和肺部问题

## Core Idea
呼吸系统问题的分水岭只有一条：**有没有呼吸窘迫**。有窘迫（胸壁凹陷、气促、发青）→ 立刻就医；没有窘迫的咳嗽 → 大多是病毒，靠时间和湿度，不靠止咳药。AAP 的明确立场：**非处方止咳药对6岁以下儿童无效且有严重副作用风险**。

## Frameworks Introduced
- **呼吸窘迫的五征（跨病种通用，最重要的判据）**：
  1. 呼吸时**肋骨与胸骨之间及周围的皮肤凹陷**（吸气性凹陷）；
  2. 呼吸加快；
  3. 高调哨声样哮鸣；
  4. 因呼吸费力而无法吮吸/吞咽/喝下液体；
  5. **嘴唇或指甲发青**（缺氧）。
  - 附加危险信号：烦躁、困倦、神志不清、呼吸时胸痛。
- **脱水五征（细支气管炎/腹泻类常见并发症）**：嘴唇发干；液体摄入少于平时；哭时无泪；尿量减少；昏昏欲睡或不再玩耍、微笑、互动。
- **哮吼的"蒸汽 15～20 分钟"法则**：洗澡时提高水温制造蒸汽，或带孩子进有蒸汽的浴室关上门陪着坐一会儿；吸入暖和湿润空气可在**15～20分钟**内改善呼吸。天冷时也可到户外呼吸凉爽湿润空气；睡觉时卧室用冷雾加湿器。
- **"病理签名式听诊/听声"鉴别法**：

| 疾病 | 声音/特征 | 好发 |
|---|---|---|
| 细支气管炎（RSV） | 先流鼻涕轻咳 → 1～2天后咳嗽加重、呼吸加快、呼吸困难 | 10/11月～次年3月；1岁以下最危险 |
| 哮吼 | 吸气时**狗叫/海豹叫样**咳嗽，夜间加重；先鼻塞发热1～2天 | 3个月～3岁；秋冬季 |
| 普通感冒 | 低热、流鼻涕、轻微少量咳嗽 | 全年 |
| 流感 | **突然**发热（多>38.3℃）、寒战、头痛肌肉痛、易疲劳、咽痛、频繁干咳 | 秋季至次年春季 |
| 肺炎 | 咳嗽+发热+呼吸困难（凹陷） | 全年 |
| 哮喘 | 咳嗽+哮鸣，夜间/运动后/接触诱因后加重；用哮喘药后好转 | 见 Ch17 |

## Key Concepts
- **细支气管炎**：肺部小气管（细支气管）感染，最常见病原为**呼吸道合胞病毒（RSV）**；几乎所有孩子在3岁前都会感染RSV，多数只是感冒，少数（尤其<1岁）发展为细支气管炎。
- **细支气管炎无特效药**：只能缓解感冒症状（加湿器、盐水滴鼻、吸鼻器）；**咳嗽是清理肺部的机制，不需止咳**；呼吸治疗未显示有帮助。
- **咳嗽持续时间的正常预期**：感冒伴流鼻涕时，咳嗽可比流鼻涕持续更久，达**2～3周**。
- **上气道咳嗽综合征**：鼻分泌物倒流咽喉后部引起难止干咳，躺下后夜间发作。
- **只夜间咳嗽** → 考虑哮喘或胃食管反流。
- **异物吸入**：约**50%**病例中，异物入肺后咳嗽在数小时或数天后才发作；**不要伸手进口抠**（会把异物推得更深）。
- **RSV 预防性注射**：<2岁且早产（孕周<29周）或高危健康状况者，可在流行季前及期间每月一次、连续3～5个月。
- **阿司匹林禁忌**：任何患流感或可能患流感的孩子都**禁用阿司匹林**（瑞氏综合征风险）。

## Reference Tables

**细支气管炎的"感染后 1～3 天"观察表**

| 时间 | 表现 | 动作 |
|---|---|---|
| 第0～1天 | 流鼻涕、轻微咳嗽、偶有低热 | 居家护理：加湿、盐水滴鼻、吸鼻、保证液体 |
| 第1～2天 | 咳嗽加重、呼吸加快 | 密切观察有无五征 |
| 任一时刻 | 出现五征之一 / 发热>3天 / <3个月婴儿发热 | **立即就医** |
| 任一时刻 | 脱水五征之一 | 就医 |
| 基础病 | 囊性纤维化、先天性心脏病、支气管肺发育不良（多数早产儿及用过呼吸机者）、免疫低下、器官移植后、化疗中 | 一旦怀疑即就医（高危） |

**退热药使用边界**

| 药物 | 适用年龄 | 备注 |
|---|---|---|
| 对乙酰氨基酚 | >3个月 | 按说明书/体重给药 |
| 布洛芬 | >6个月 | **不用于脱水或持续呕吐的孩子** |
| 阿司匹林 | **儿童流感/疑似流感禁用** | 瑞氏综合征风险 |
| 非处方止咳药 | **6岁以下无效且可能严重副作用**（AAP立场） | 不用 |

## Mental Models
- **"咳嗽不是敌人，是清洁工"**：镇咳等于关掉清理系统；重点是加湿、补液、观察呼吸。
- **"数呼吸比听咳嗽有用"**：家长最容易漏掉的是呼吸频率与凹陷，而不是咳得多响。
- **"加湿器必须每天洗"**：不洗就是细菌与真菌的培养箱，反而致病。
- **"流感 ≠ 胃肠型感冒"**：流感主要损害呼吸系统，也可伴腹痛呕吐腹泻，但别与"上吐下泻"的胃肠炎混为一谈。
- **"哮吼别用手指扩张气道"**：梗阻来自内部组织肿胀，手指解决不了，只会加重恐慌。

## Anti-patterns
- **给幼儿用非处方止咳药**：无效 + 风险。
- **给流感孩子吃阿司匹林退热**：瑞氏综合征。
- **用止咳糖浆治哮吼**：无效。
- **用抗生素治哮吼或细支气管炎**：多为病毒，无效（哮吼必要时用皮质激素）。
- **孩子呛咳时伸手进口抠异物**：可能把异物推深。
- **加湿器长期不清洗**：成为污染源。
- **把"咳嗽2～3周"当异常**：感冒后咳嗽本就可能持续这么久。

## Worked Example
一个10个月婴儿"感冒后加重"的分流：

| 观察 | 判读 |
|---|---|
| 10月起病，先流鼻涕轻咳2天 | 符合RSV季节与初期表现 |
| 第3天咳嗽加重、呼吸约50次/分、吸气时肋间凹陷 | **呼吸窘迫** → 立即就医，不再居家观察 |
| 吃奶量下降但能喝水，哭时有泪、尿量正常 | 尚无脱水，但需持续监测五征 |
| 体温38.2℃，持续2天 | 未达"发热>3天"红线，但与窘迫并存 → 一并就诊 |
| 处置 | 加湿、盐水滴鼻、吸鼻、少量多次喂水；**不用止咳药、不用抗生素**；医生评估是否需支持治疗 |

对照哮吼：若为"夜间突发狗叫样咳 + 吸气有高调声"，先做蒸汽15～20分钟，观察是否改善；出现嗜睡、说不出话、咳时脸发青 → 立即急诊。

## Key Takeaways
1. 一切呼吸问题先看五征：凹陷、气促、哮鸣、无法进食、发青——有其一即就医。
2. 6岁以下不用非处方止咳药；流感/疑似流感禁用阿司匹林。
3. 细支气管炎无特效药，靠加湿、补液、观察；高危儿（早产<29周等）可考虑RSV预防性注射。
4. 哮吼用蒸汽15～20分钟；皮质激素有效，抗生素与止咳糖浆无效。
5. 异物吸入的咳嗽可能延迟数小时至数天出现；绝不伸手抠。

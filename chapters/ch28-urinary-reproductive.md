# 第28章 泌尿和生殖系统问题

## Core Idea
这一章有两个"先别急着动刀"的判断：**尿道下裂的孩子先不要割包皮**（包皮可能是修复材料）；**阴唇粘连多数会自愈**，无症状就观察。另有两条日常误判要纠正：**红色尿不一定是血尿**，**睾丸"消失"多数是正常回缩**。

## Frameworks Introduced
- **"真假血尿"鉴别**：先排除食物与药物导致的尿色改变，再谈血尿。

| 使尿变红/橙的物质 | 类别 |
|---|---|
| 甜菜、黑莓、红色食用色素 | 食物 |
| 酚酞（部分泻药成分） | 药物/化学物 |
| 非那吡啶（缓解膀胱疼痛） | 药物 |
| 利福平（抗结核药） | 药物 |

  - 真血尿的线索：伴排尿疼痛（提示尿路感染）；**看血出现在尿流的哪个时段**（全程带血 vs 排尿末带血）可帮助定位出血来源。
  - 伴蛋白尿 → 多提示肾炎或肾滤过膜炎症。
- **包皮环切的决策时机**：应在**出生前**与伴侣、产科医生或儿科医生讨论清楚；不是所有男婴都必须做，但当前数据表明**益处大于风险**；决定权在父母。
- **"先别割"的红线**：新生儿确诊**尿道下裂或阴茎下弯**时，须先咨询小儿泌尿科/外科医生，**再**考虑是否环切——因为包皮可能用于将来的尿道口修复，先切会让手术变难。

## Key Concepts
- **蛋白尿**：尿蛋白异常升高提示肾滤过膜异常；可无症状，但血蛋白降低时会出现腿、脚踝、腹部或眼睑肿胀，血压也可能升高。诊断靠试纸初筛 + 晨起第一次尿送检 + 血液检测；必要时肾脏活检（镇静 + 局部麻醉）。
- **包皮环切**：切除覆盖龟头的包皮；非健康必需，取决于父母选择。
- **尿道下裂**：尿道口位于阴茎底部而非龟头；可伴阴茎下弯（成年后影响性功能）；尿流向下、站立排尿困难。轻者可不治，中重度需手术，**多在6个月左右修复**；严重者可能需多次手术。目标：正常排尿、成年正常性功能、外观可接受。
- **尿道口狭窄**：尿道口周围瘢痕使开口变小，**最常见于3～7岁**（尤其环切过的男孩）；表现为尿流细、方向异常（向上喷）、排尿时间长、排不空、滴尿或喷洒。
- **阴唇粘连**：多因尿布区反复刺激发炎（尿液、强刺激清洁剂、人造纤维内裤）；可致排尿困难或易尿路感染；**多数随年龄自愈**，无症状无需治疗；治疗选项为观察等待、每天涂雌激素乳膏数次、麻醉下手法分离。雌激素乳膏可能致处女膜外观暂时改变或停药后出血（类似月经），分离时局部可能出现淤青（会被误认为创伤）——都会自行消退。坐浴与边缘涂润滑剂有助于防复发。
- **后尿道瓣膜**：男婴尿道内黏膜横贯阻碍排尿，影响膀胱与肾发育，可危及生命；多在产前超声发现（羊水减少为线索）；出生后可表现为膀胱充盈增大、持续滴尿、尿流无力，或**第一年发生尿路感染伴发热与食欲不振**；需立即处理（导尿缓解 + 影像 + 手术切除瓣膜）。
- **隐睾**：睾丸未降入阴囊；多数在出生后头几个月完成下降；**正常男孩会有"回缩"现象**（冷水、紧张或医生检查时暂时"消失"），需与真隐睾区分。

## Reference Tables

**男孩生殖系统问题的"该不该手术"速查**

| 问题 | 是否手术 | 时机与要点 |
|---|---|---|
| 包皮环切 | 非必需，父母选择 | 出生前讨论；益处>风险 |
| 尿道下裂/阴茎下弯 | 轻者可不治；中重度需修 | 6个月左右；**术前不环切**（保留包皮作修复材料） |
| 尿道口狭窄 | 视情况，手术是小手术 | 3～7岁常见；尿流细/排尿费劲/滴尿即就医 |
| 后尿道瓣膜 | 需手术 | 确诊后立即导尿缓解 + 影像 + 切瓣膜；查肾功能 |
| 隐睾 | 视是否自行下降 | 出生后头几个月观察；未降需专科评估 |
| 鞘膜积液 | 多数不需 | 数月内自行吸收（见 Ch5） |

**血尿的检查路径**

1. 病史：外伤？特殊食物/药物？排尿疼痛？血出现在尿流哪一段？
2. 体检：血压是否升高、肾区触痛、手/脚/眼周是否肿胀。
3. 化验：尿常规、血液检测。
4. 影像：超声或X线。
5. 仍无病因且持续 → 小儿肾脏科；必要时肾脏活检。
6. 随访：定期尿检、血检、测血压（排查慢性肾脏病）。

## Mental Models
- **"排尿的'形状'是诊断信息"**：尿流细、向上喷、滴尿、喷洒、排尿时间长——都在描述梗阻的位置与程度。
- **"女孩外阴问题先想刺激，男孩外阴问题先想梗阻"**：阴唇粘连源于尿布区刺激；尿道口狭窄、后尿道瓣膜都是梗阻。
- **"睾丸时隐时现不是病，一直不在才是病"**：回缩是正常反射。
- **"血尿多数无需治疗，但必须随访"**：少数需消炎或手术，长期随访是为了排除慢性肾脏病。

## Anti-patterns
- **给尿道下裂的孩子先做包皮环切**：会让后续修复变难。
- **把红色尿一律当血尿**：先查饮食与药物。
- **给无症状的阴唇粘连做激进处理**：多数会自愈。
- **忽视男孩"尿流细、排尿费劲"**：可能是尿道口狭窄或后尿道瓣膜。
- **把婴儿"持续滴尿、膀胱充盈"当正常**：是梗阻信号。
- **认为隐睾可以等到青春期再看**：应在出生后数月内评估。

## Worked Example
一个5岁男孩"小便要很久、尿往上喷"：

| 观察 | 判读 |
|---|---|
| 尿流细、方向向上（朝房顶）、需把阴茎往下拉才不溅出 | 典型尿道口狭窄表现 |
| 排尿时间长、排不空 | 梗阻而非习惯问题 |
| 有包皮环切史 | 尿道口受刺激形成瘢痕的常见背景 |
| 年龄5岁 | 落在3～7岁高发区间 |
| 决策 | 就医诊断；如需治疗为小手术，术后短期不适即消失 |

对照：若是"1岁男孩发热 + 食欲不振 + 反复尿路感染"，要警惕**后尿道瓣膜**，需立即就医并查膀胱与肾脏影像。

## Key Takeaways
1. 红色尿先排除甜菜、黑莓、色素、酚酞、非那吡啶、利福平，再谈血尿。
2. 尿道下裂/阴茎下弯的孩子**术前不要环切**，包皮是修复材料。
3. 男孩尿流细、向上喷、排尿费劲（3～7岁常见）→ 想尿道口狭窄。
4. 阴唇粘连多数自愈；只在排尿困难或反复尿路感染时才需治疗（观察/雌激素乳膏/手法分离）。
5. 隐睾要与正常"回缩"区分；婴儿持续滴尿 + 膀胱充盈 → 警惕后尿道瓣膜。

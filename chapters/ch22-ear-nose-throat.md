# 第22章 耳、鼻、咽喉问题

## Core Idea
这一章的核心判据只有两条：**"是不是细菌感染"**（决定用不用抗生素）和**"病程是否超过时间窗"**（决定要不要复诊）。感冒是病毒、抗生素无效；中耳炎70%继发于感冒、该用抗生素但必须服完疗程。

## Frameworks Introduced
- **感冒的分诊时间窗**（3个月以上孩子，出现任一即咨询医生）：
  - 呼吸窘迫：每次呼吸鼻孔变大（鼻翼扇动）、吸气时肋间与胸骨周围凹陷、呼吸急促；
  - 嘴唇或指甲发青；
  - **10～14天后依然有鼻涕**；
  - **日间咳嗽持续10天以上**；
  - 耳部疼痛，或持续烦躁哭闹；
  - **体温超过38.9℃**；
  - 过度困倦或脾气暴躁。
  - 另加一条绝对规则：**孩子≤3个月，一旦生病即就医**（症状具有误导性，可能快速进展为细支气管炎、哮吼或肺炎）。
- **感冒病程预期**：出生头两年多数孩子感冒8～10次；无并发症的典型感冒症状在**7～10天**内逐渐消失；若1周内未完全恢复、或不是一天天好转 → 再次告知医生。
- **抗生素三问（避免滥用）**：
  1. 这是细菌感染吗？（病毒性无效）
  2. 若是细菌性，48～72小时无改善 → 问下一步怎么办；
  3. 必须服完全疗程（症状好转就停药 → 细菌复发 + 耐药）。
- **中耳积液的"时间-听力"规则**：中耳炎治愈后仍约**半数**孩子有积液，其中**90%在3个月内自行消失**；但**双耳积液≥3个月、或单耳积液≥6个月 → 需听力检查**（听力直接关系语言发育）。

## Key Concepts
- **感冒传播路径**：飞沫（喷嚏/咳嗽）直传 + 手-物-手间接传播（摸鼻子/咽喉即完成接种）。
- **中耳炎**：70%继发于感冒；高发6个月～3岁；约2/3孩子在2岁前至少一侧感染；约1/3伴发热38～40℃。
- **中耳炎的风险因素**：托幼机构（病菌多）、**仰卧自己用奶瓶吃奶**（奶液流入咽鼓管）、二手烟、男性、家族史。
- **中耳炎的其他表现**：吃奶时哭得更凶（吮吸吞咽增加中耳压力）、入睡困难、平衡感变差/动作笨拙、耳道流出带血丝黄色液体或脓液（提示鼓膜穿孔，多可自愈但需向医生描述性状）。
- **分泌性中耳炎**：感染控制后积液仍存，可致暂时性听力下降；也常因咽喉上方腺体肿大导致引流不畅。
- **游泳性耳病（外耳道炎）**：夏季耳痛明显、触碰或拉耳廓时加重；外耳道皮肤感染，不造成长期听力损失。
- **生理盐水滴鼻法**：哺乳前15～20分钟每侧各滴2滴生理盐水，随后立即吸出；**绝不用含药物成分的滴鼻液**（婴儿易吸收过量）。吸鼻器用法：先捏球部→轻插→慢松。
- **加湿器**：用**冷雾**型，每天按说明书彻底清洗晾干；**不推荐热蒸汽加湿器**（烫伤风险）。

## Reference Tables

**感冒症状谱与转诊阈值**

| 症状 | 预期 | 转诊阈值 |
|---|---|---|
| 流鼻涕 | 起初清涕，后变黏稠有色 | >10～14天 |
| 发热 | 38.3～38.9℃，夜间明显 | >38.9℃；或≤3个月任何发热 |
| 咳嗽 | 可持续2～3周 | 日间咳嗽>10天 |
| 食欲 | 降低 | 持续下降 + 精神差 |
| 咽喉痛 | 可伴吞咽困难 | 严重咽痛 + 发热（查链球菌） |
| 颈部 | 轻微腺体肿大 | 明显肿大 |

**中耳炎用药与随访**

| 情形 | 处理 |
|---|---|
| 疑似耳部感染 | 立即咨询医生；先用对乙酰氨基酚/布洛芬止痛（不用阿司匹林） |
| 已开抗生素 | 严格按时间表服完；通常2天内明显好转 |
| 服药48～72小时仍耳痛+高热 | 复诊（可能需换药、加药或注射） |
| 鼓膜穿孔 | 多数自愈；**痊愈前不能游泳**；可乘飞机但起降时止痛+饮水 |
| 能否上学 | 不发热、疼痛不重、精神好即可上学（需能按时服药） |

## Mental Models
- **"感冒没有特效药，能做的是让孩子舒服"**：休息、补水、单一成分退热药、生理盐水+吸鼻器、冷雾加湿。抗生素对病毒无效。
- **"<3个月发热是红线"**：小婴儿症状会骗人，宁可直接就医。
- **"该吃药时没吃够，比不该吃时吃了更糟"**：前者培养耐药菌。
- **"耳朵问题最终是语言问题"**：反复中耳炎/长期积液 → 听力下降 → 语言发育受影响，因此随访与听力检查不能省。
- **"咳嗽是清理机制"**：6岁以下非处方止咳药无效且有严重副作用（AAP立场）。

## Anti-patterns
- **要求医生给感冒开抗生素**：无效且有害。
- **症状好转即停抗生素**：细菌残留、复发、耐药。
- **用含药滴鼻液给婴儿通鼻**：吸收过量风险。
- **用热蒸汽加湿器**：烫伤风险。
- **让婴儿仰卧自己抱奶瓶吃奶**：增加中耳炎风险。
- **家中有人吸烟**：显著提高中耳炎、细支气管炎、肺炎、哮喘风险。
- **把中耳炎当"必须在家休息"**：不发热、精神好可以上学。

## Worked Example
一个1岁半孩子"感冒第9天还没好"的处置：

| 观察 | 判读 |
|---|---|
| 第1～3天：清涕、低热37.8℃、轻咳 | 典型病毒性感冒，居家护理 |
| 第4～7天：鼻涕变稠变黄 | 正常病程（不是"转细菌"的证据） |
| 第8天夜间：抓右耳哭闹、吃奶时更凶、体温38.7℃ | 疑急性中耳炎（吮吸吞咽加重疼痛） |
| 第9天 | 就医；医生开抗生素 + 止痛 |
| 用药2天 | 明显好转 → **仍服完全疗程** |
| 疗程结束后复诊 | 查中耳是否仍有积液；若持续→按"双耳3个月/单耳6个月"规则安排听力检查 |

## Key Takeaways
1. ≤3个月婴儿一发病就就医；>3个月看七条红线（尤其鼻涕>10～14天、日咳>10天、体温>38.9℃）。
2. 感冒是病毒，抗生素无效；典型病程7～10天，咳嗽可拖2～3周。
3. 中耳炎70%继发于感冒；抗生素必须服完全疗程，48～72小时无改善要复诊。
4. 积液随访规则：双耳≥3个月、单耳≥6个月 → 查听力（关系语言发育）。
5. 通鼻只用生理盐水 + 吸鼻器；加湿器只用冷雾并每日清洗。

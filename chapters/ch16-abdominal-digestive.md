# 第16章 腹部、消化道问题

## Core Idea
腹痛的判读靠两把尺子：**年龄**（婴儿与年长儿的病因谱完全不同）和**疼痛的迁移路径**（起点在哪、往哪走、和呕吐谁先谁后）。绝大多数腹痛会自行缓解，真正要命的只有少数几个，而它们都有可识别的签名。

## Frameworks Introduced
- **"痛与吐的先后顺序"鉴别法**（最简单也最救命的一条）：
  - **先痛后吐**（腹痛几小时后才呕吐）→ 高度怀疑**阑尾炎**；
  - **先吐后痛**（呕吐后出现腹痛）→ 更常见于胃肠炎等胃部病毒感染。
- **腹痛就医的五条红线**（出现任一立即就医）：
  1. 持续腹痛，或3～5小时后加重；
  2. 伴发热和严重咽喉痛；
  3. 明显且持续的食欲下降；
  4. 精神不振；
  5. 腹痛持续2小时以上 + 恶心/呕吐/无食欲/发热（阑尾炎组合征）。
- **便秘的"布里斯托式五型"自评（本书版）**：
  - 类型1：排便痛苦，大便非常浓稠致密，呈岩石/卵石/小球状，难以排出；
  - 类型2：起初难排，卵石状；
  - 类型3：柔软易排，圆木状；
  - 类型4：非常柔软半固态，易排或爆炸式排出；
  - 类型5：液态，快速排空，难以控制。
  - 判读：长期停留在1～2型=便秘；3型为理想。
- **纤维摄入公式**：每日纤维克数 ≥ **年龄 + 5**（3岁 → 至少8克）；每天共5份水果蔬菜。
- **"憋便—积留—失禁"恶性循环**：排便疼痛 → 孩子下意识憋回 → 大便在直肠积留变干变硬变长 → 失去便意 → 只能靠灌肠/导泻 → 液态粪水绕过硬块漏出（家长误当腹泻或遗粪）。

## Key Concepts
- **肠痉挛**：10天～3个月高发，3个月后好转，最晚1岁消退；下午傍晚加重、蹬腿、放屁、无法安抚。
- **肠套叠**：2岁以下最常见的腹部急症；间断性剧烈哭闹 + 双腿向腹部屈曲 + 呕吐 + **"黑莓酱样"深色黏液血便**；哭闹间期可完全安静甚至困倦（易被误判为好转）。
- **乳糜泻**：对麸质（小麦/黑麦/大麦/部分燕麦蛋白）的异常免疫反应破坏肠黏膜→吸收障碍；可无症状；确诊需血液检测 + 小肠活检；**必须终生严格无麸质**（大米制品可作主食）。
- **牛奶过敏**：对牛奶蛋白的免疫反应，痉挛性腹痛 + 呕吐/腹泻/血便/皮疹。
- **铅中毒**：老房（1960年代前）含铅涂料 + 幼儿啃墙皮/漆片；症状含腹痛、便秘、烦躁、困倦、抽风；**9～12个月建议血铅筛查**（小婴儿常无症状）。
- **链球菌咽喉炎**：2岁以上高发；咽痛+发热+腹痛（细菌刺激肠道）；可伴肛周感染致疼痛、憋便、腹痛。
- **情绪性腹痛**：学龄期反复腹痛、持续1周以上、与压力事件相关、查不出伴随症状；常有家族聚集。

## Reference Tables

**阑尾炎症状出现顺序（按时间）**

| 顺序 | 表现 | 要点 |
|---|---|---|
| 1 | 腹痛 | 始于**脐周**，逐渐转移并加重于**右下腹**；婴儿表现为哭闹、任何姿势都不舒服；位置异常者可痛在腹部其他部位或背部，甚至出现尿频、尿灼热；可因炎症刺激腿部肌肉而跛行或走路弯腰 |
| 2 | 呕吐 | 痛后数小时出现（**先痛后吐**是阑尾炎特征） |
| 3 | 无食欲 | 疼痛开始后不久饥饿感消失，连喜欢的食物也不吃 |
| 4 | 发热 | 多38～39℃；穿孔时更高 |

**陷阱**：疼痛突然消失可能意味着阑尾已破溃穿孔——危险度反而升高，随后出现高热，需住院手术+抗生素。

## Mental Models
- **"哭闹间期安静 ≠ 好转"**：肠套叠与阑尾炎都有"假平静期"。看整体模式，不看清淡的那几分钟。
- **"3岁以下阑尾炎极罕见，但一旦发生最难诊断"**：他既说不清位置，也无法描述"转移痛"。所以判断依据是"和平时不一样、看起来更严重"，而不是"像不像阑尾炎"。
- **"便秘是一种行为病，不只是饮食病"**：如厕训练期（2～5岁）的憋便是主因之一；治疗必须同时改饮食、改姿势、重建排便习惯。
- **"没有明确诊断就别自行开始无麸质饮食"**：会让血清与组织标志物消失，此后需重新吃几个月麸质才能确诊。

## Anti-patterns
- **把肠套叠的"安静期"当好转而等待**：延误可致肠坏死。
- **用"痛在吐后"安慰自己**：这条只降低阑尾炎概率，不排除其他急症。
- **便秘只靠软便剂不改正姿势**：脚必须平踏地板/脚凳，腹肌才能发力（悬空坐马桶时腹肌在忙着保持平衡）。
- **自行给幼儿用非处方软便剂**：须先咨询医生。
- **未确诊即长期无麸质饮食**：干扰诊断。
- **忽略老房子的墙皮与旧漆玩具**：铅中毒症状常被当成"肠胃不好+脾气差"。

## Worked Example
一个3岁孩子"肚子疼"的分诊路径：

| 观察项 | 结果 | 判读 |
|---|---|---|
| 起病 | 脐周隐痛4小时，逐渐偏右下 | 红旗：疼痛迁移 |
| 呕吐与痛的顺序 | 先痛，2小时后吐一次 | 支持阑尾炎，非胃肠炎 |
| 食欲 | 连最爱的面条也不吃 | 红旗：无食欲 |
| 体温 | 38.4℃ | 红旗：发热 |
| 大便 | 3天未排、干硬小球状（类型1） | 并存便秘，但不能解释迁移痛 |
| 决策 | 持续>2小时 + 呕吐 + 无食欲 + 发热 → **立即就医** | 不自行观察、不用止痛药掩盖症状 |

对照：若为"先吐后痛 + 稀水便 + 全家先后发病" → 胃肠炎，以补液为主，多数几天到1周自愈。

## Key Takeaways
1. 腹痛第一条判据：**先痛后吐疑阑尾，先吐后痛多胃肠炎**。
2. 五条红线（持续/加重、发热+咽痛、持续无食欲、精神不振、>2小时伴呕吐）任一出现即就医。
3. 肠套叠签名：间断剧烈哭闹 + 双腿屈腹 + 呕吐 + 黑莓酱样血便；安静期不是好转。
4. 便秘治疗三件套：纤维（年龄+5克）+ 足量水 + 脚踏实地的排便姿势；2～5岁憋便是主因。
5. 乳糜泻须"先确诊、后终生无麸质"；9～12个月建议血铅筛查。

# 第3章 婴儿的基本护理

## Core Idea
头一个月的护理只有两条主线：**哭闹要快速回应**（这么小的孩子不会被宠坏），**睡眠要守安全底线**（仰卧、硬床垫、床内无杂物）。其余日常（尿布、洗澡、穿衣、剪指甲）都是可练熟的技能，不是天赋。

## Frameworks Introduced
- **哭闹分层响应法**：按"最迫切需求"排序处理，而不是逐项试错。
  - 第1层：冷/饿/湿 → 先保暖，再换尿片，最后喂奶。
  - 第2层：排除生理需求后，按安抚清单逐一试（摇、抚触、襁褓、唱歌、轻音乐、推车走动、白噪声、拍嗝、热水澡）。
  - 第3层：全都不管用 → 放回安全处独处片刻（很多婴儿哭一哭才睡得着）。
  - 第4层：声嘶力竭、不分昼夜 → 考虑肠痉挛；伴直肠温度≥38℃ → 立即就医。
- **安全睡眠五要素（SIDS 防线）**：仰卧 + 硬质床垫 + 床内无软物 + 与父母同房不同床 + 睡袋/连体睡衣代替毯子。
  - Why it works: 俯卧睡得更沉、更难醒来；1992年推荐仰卧后美国婴儿猝死率下降50%以上。侧卧同样危险（会翻成俯卧）。
- **睡前程序四步**：感官刺激（洗澡）→ 放松（润肤/讲故事/唱歌）→ 当天最后一次奶 → 简短睡前故事（"现在开始睡大觉"的信号）。
- **襁褓三规则**：髋膝留活动空间、胸口贴合但可插入成人一只手、只在仰卧时用，出现翻身迹象（2～3个月）立即停用。

## Key Concepts
- **婴儿猝死综合征（SIDS）**：1岁以下婴儿（新生儿期之后）死亡的首要原因。
- **快速眼动/非快速眼动睡眠**：新生儿每段睡眠由两者几乎等长组成；6个月后非快速眼动才明确分四阶段。
- **肠痉挛**：对外界刺激过度敏感或神经系统无法自我调节所致，随月龄改善；市售滴剂研究证明无效。
- **俯卧练习**：清醒且有看护时的俯卧，锻炼肩部与头部控制，并防止后脑扁平。
- **睡姿固定垫/卷毯**：不应用于固定睡姿，有窒息风险。

## Mental Models
- **"哭是沟通，不是操纵"**：新生儿每天平均哭1～4小时，这是他适应子宫外世界的方式；回应越快，哭得越短。
- **把"哄睡"降级为"陪睡"**：在孩子昏昏欲睡但未完全睡着时放下，他才学得会自己入睡；总是摇到睡着，就等于替他关掉了这项能力。
- **睡眠时长按体重解锁**：体重达5.5～6千克且吃饱，多数婴儿可连睡6小时；4个月前或5.4千克前长时间不间断睡眠反而不正常。
- **任何情况下都不能大力摇晃**：可致失明、脑损伤、死亡——这条要转告所有看护者。

## Anti-patterns
- **用侧卧或俯卧"防止呛奶"**：无证据支持，且显著提高SIDS风险；胃食管反流婴儿也应仰卧。
- **母婴同床睡**：增高婴儿死亡风险；正确做法是同房不同床（婴儿床/摇篮放父母房间）。
- **在汽车座椅、推车、秋千、背带里让婴儿久睡**：尤其4个月以下，身体无法固定易窒息。
- **哭闹时家长情绪失控**：先放孩子在安全处，再求助换人——自己的紧张会让婴儿哭得更凶。

## Worked Example
夜间哭闹的处置顺序（一位新手父母的实际决策链）：

1. 先摸后颈/腹部：偏凉 → 加一层衣物（新生儿比身边大人多穿一层）。
2. 尿片湿透 → 迅速换（夜奶时尽量不开亮灯、不逗玩）。
3. 仍哭 → 喂奶（按需，8～12次/24小时）。
4. 吃完仍烦躁 → 拍嗝排胀气。
5. 仍哭 → 按清单试：裹襁褓（髋部放松）→ 抱着走动 → 白噪声。
6. 越哭越凶、双腿蜷缩、每天固定时段发作 → 记为肠痉挛，放慢哺乳节奏、调整母亲饮食、适当拍嗝。
7. 声嘶力竭不停 + 测直肠温度 ≥38℃ → 就医。
8. 家长已到极限 → 把孩子放回婴儿床，换另一位看护者接手，自己离开房间10分钟。

## Key Takeaways
1. 新生儿哭闹必须快速回应，前几个月不存在"宠坏"。
2. 仰卧是唯一推荐睡姿，侧卧与俯卧同样危险；床内不放枕头、被子、防撞垫、毛绒玩具。
3. 襁褓只在仰卧、髋部可动、胸口能插入一手的前提下使用，2～3个月出现翻身迹象就停。
4. 5.5～6千克是"能睡长觉"的体重信号，在此之前整夜安睡不是目标。
5. 直肠温度≥38℃ + 无法安抚的哭闹 = 立即就医；任何时候都禁止摇晃婴儿。

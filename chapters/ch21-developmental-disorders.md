# 第21章 发育障碍

## Core Idea
发育差异与发育障碍的分界线是**持久性 + 是否丧失已获得的技能**。孩子之间的短期差异很常见（多数会自行追平），但"明显迟缓"必须尽早评估——因为**早期干预能改变结局**，这是本章唯一的行动指令。

## Frameworks Introduced
- **发育障碍的判定双条件**（满足任一即需评估）：
  1. 生理或心理发育**未达到对应月龄的里程碑**（对照 Ch6–Ch13）；
  2. 孩子**失去了先前已获得的技能**（退行是最强信号）。
- **评估转介链**：儿科医生 → 发育与行为儿科 / 儿童神经科 / 遗传学 / 儿科康复医师 → 物理治疗师（PT）、言语语言治疗师（ST）、作业治疗师（OT）。3岁以下有迟缓或高危者，通常直接进入**早期干预**。
- **早期干预的权利框架（美国）**：3岁以上有发育障碍的儿童有权在**限制最少的环境**中接受免费、合适的公共教育；3岁以下多有专门早期教育项目，可在**家中**进行；3～5岁可在幼儿园或家中。
- **父母即治疗师原则**：早期干预最重要的原则之一是教会父母治疗技术，使干预在疗程之外持续发生。

## Key Concepts
- **孤独症谱系障碍（ASD）**：影响行为、社交技巧与沟通，终生伴随。现已合并原来自闭症、阿斯伯格综合征、儿童崩解症、PDD-NOS 四类诊断。
- **ASD 的表现层次**：非语言交流困难（手势、指物、眼神、模仿）多在**第1年**出现；语言问题在**第2年**更明显；重复性行为出现更晚（反复开关灯、重复话语、单一话题、摇摆拍手）。
- **ASD 的流行病学**：美国约每59名儿童1例；男:女 ≈ 4:1；近年诊断增加主要源于识别率提高与诊断标准合并。
- **疫苗与孤独症**：多项研究已验证并**有效排除**二者关联；导致孤独症的大脑变化始于子宫，远早于接种。
- **大脑性瘫痪（脑瘫）**：每1000名儿童2～3例；约一半智力正常；类型包括偏瘫、双侧瘫、四肢瘫，肌张力可高可低或两者并存；多因产前脑发育异常，**多数并非分娩缺氧所致**（AAP 与 ACOG 联合报告）。
- **"模仿言语"**：重复听到的话而非按词义使用，是ASD语言特征之一。

## Reference Tables

**ASD 早期里程碑筛查表（"该年龄应具备"的能力）**

| 年龄 | 应具备 |
|---|---|
| 快1岁 | 你说"看！"并用手指物时，他会看那个物品；会做简单手势（挥手再见）；会说"mama""baba"或至少一个其他词 |
| 快1岁半 | 会主动指给你看他感兴趣的东西；至少正确使用10个词；愿意玩扮演游戏（喂娃娃吃饭） |
| 快2岁 | 能指出一些身体部位、物品与图片；能模仿成人或大孩子的行为；能说2词句，词汇≥50 |
| 快3岁 | 喜欢和其他孩子一起玩（不只是各玩各的）并模仿他们；能说3词句、使用一些代词；会和娃娃说话或在扮演游戏中扮演角色 |
| 快4岁 | 被问时能说出朋友的名字；能回答"什么/什么时候/谁/在哪里"；能清楚说出5～6词句 |

**ASD 症状谱（不同孩子组合不同）**

| 领域 | 可能表现 |
|---|---|
| 语言 | 不会说话或迟缓/不良；重复语言；无法开始或延续对话；不遵守交谈与讲故事规则 |
| 非语言 | 难以理解他人话语、表情、肢体语言；指物延迟或方式奇怪；叫名字不回应但对狗叫或薯片袋声有反应 |
| 社交 | 被动、回避眼神；似乎不知道周围发生了什么；只沉浸在自己世界 |
| 行为 | 反复摇摆、旋转、拍手、排列物品；被旋转物体吸引；可能出现撞头、咬东西等自伤或攻击 |
| 兴趣 | 极狭窄、重复；不按玩具本来的玩法玩（只玩卡车车轮）；反复排成一排；想象/扮演游戏迟缓 |
| 偏好 | 不喜欢毯子或毛绒玩具，偏爱线、木棍、雕像等奇特物品且不愿放手 |
| 感官 | 对气味、光、声、触、质敏感；疼痛阈值似乎更高 |
| 变化 | 日常改变（如吃饭时间）或被打断时暴怒、发脾气、破坏行为 |

**干预方式**

- 应用行为分析（ABA）
- 发展性干预（如"地板时光"）
- 结构化教育法
- 强度要求：年幼儿童可受益于综合方案 + **每周25小时一对一、全年持续**
- 社交技能团体治疗（各年龄均可能有益）
- 药物：作为整体方案的一部分控制相关行为问题，学龄儿童与青少年更常用

## Mental Models
- **"退行比迟缓更紧急"**：会说的话不说了、会的动作不会了，优先评估。
- **"诊断不是门槛，干预不需要等确诊"**：一旦怀疑ASD，即使尚未确诊也应开始治疗；其他发育问题同样受益于早期干预。
- **"限制最少的环境 ≠ 最少帮助"**：有的孩子在小环境干扰少更有利，有的在大环境可模仿同伴更有利——按孩子匹配，而非按理念。
- **"不要用短期比较判断发育"**：邻家孩子10个月会走、你家12个月还不会，这类差距通常不会持续；看趋势与整体。

## Anti-patterns
- **"等等看，长大就好了"**：对真正迟缓的代价是错过干预窗口。
- **因担心ASD而拒绝接种疫苗**：已被大量研究排除因果，且脑部变化早于接种。
- **只做单一疗法、拒绝综合方案**：ASD 无根治方法，需针对症状组合干预。
- **忽视听力检查**：任何语言迟缓的孩子都必须先评估听力。
- **把脑瘫归咎于分娩**：多数并非产时缺氧造成，误判会耽误寻找真正病因。

## Worked Example
一个20个月幼儿"还不会说话"的分诊路径：

| 观察项 | 结果 | 判读与动作 |
|---|---|---|
| 词汇量 | 约6个词 | 低于"1岁半≥10词"的里程碑 |
| 指物 | 会拉大人的手去够，但不用食指指 | 非语言交流异常信号 |
| 叫名字 | 常不回应；但对开门声有反应 | 需先做**听力评估** |
| 眼神与模仿 | 眼神接触少，不模仿拍手 | ASD 相关信号 |
| 扮演游戏 | 不会喂娃娃 | 1岁半应有 |
| 动作 | 已会走、会跑，无退行 | 大运动正常 |
| 决策 | 立即转介：听力检查 + 发育评估（18～24个月本就应做ASD筛查）；**同时开始早期干预，不等确诊** | |

## Key Takeaways
1. 判定发育障碍：未达里程碑，**或**丧失已获得技能（退行最需警惕）。
2. 语言迟缓第一步永远先查听力；18～24个月应做ASD筛查。
3. 怀疑即干预——不需要等确诊；父母是干预团队的核心执行者。
4. ASD 男女比约4:1，美国约1/59；疫苗与ASD的关联已被研究排除。
5. 3岁以下早期干预可在家进行；3岁以上有权在限制最少的环境接受免费适当教育。

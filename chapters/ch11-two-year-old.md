# 第11章 2岁

## Core Idea
"可怕的2岁"的本质不是叛逆，而是**大脑在同时处理"我要独立"和"我还依赖你"两套冲动**。这一年的正确姿势：接受这种摇摆、给明确而稳定的规矩、把"发脾气"当作情绪学习而非对抗。

## Frameworks Introduced
- **发脾气五步法**（本章最实用的操作序列）：
  1. 情绪刚起时先尝试转移注意力到别的活动；
  2. 转移失败（多数情况）→ 先**命名并承认**他的感受（"你现在很暴躁，因为我们得走了，可你还不想走"），不理论、不吼、不责备、不惩罚，也不靠满足所有要求来平息；
  3. 告诉他你会给他时间平静，确保安全后给他空间自己度过；
  4. 公共场合 → 立刻带走，不多说、不大惊小怪，平静后再返回；
  5. 出现打人/咬人等伤人行为 → 立即明确制止 + 当场短暂隔离（"到旁边待一会儿"），并让他关注被打孩子的感受。
  - 关键时效：惩罚必须当场，1小时后再罚他无法与"罪行"建立联系。
- **"共情命名"技术**：把他正在体验的情绪说出名字，是教他管理情绪的第一步。"被理解"本身就有安抚作用。
- **语言障碍筛查线**：每10～15个孩子就有1个存在语言理解或表达障碍；2岁词汇＜50个或不会组2词句，需评估（先查听力）。

## Key Concepts
- **头围**：出生第2年只增约2厘米；此后10年共增2～3厘米。
- **身高体重**：5岁前平均每年身高＋6厘米、体重＋2千克。
- **食量变小**：发育放缓→热量需求下降，吃少是正常的；但持续提供多样健康食物、全家安静共餐。
- **"可怕的2岁"的两面**：一会儿缠你、一会儿跟你对着干；"不"和"我的"成为高频词。
- **自我中心归因**：他认为"世界上每件事都源于我做过的事"——所以父母离婚、家人生病，他会以为自己有责任。
- **幻想与现实不分**：不说"你再吃就会把肚子撑破"这类玩笑，他会当真并恐惧。

## Mental Models
- **"多动是2岁的默认值"**：跑跳爬、坐不住、语速快、注意力易转移都正常，多在入学前消失。与其改造孩子，不如改造期望——不指望他在长会议或餐厅里从头坐到尾。
- **"安静的孩子不等于省心"**：攻击性强的与安静害羞的同样"正常"，都需要被看见。
- **规矩要"少而硬"**：定明确、合理的规矩并前后一致地执行；配合规律的作息（睡、三餐、洗澡、小睡）给他可预测的世界。
- **模仿是"身教优先"的证据**：他扮演父母时学的是你的语气和做法，不是你的说教。

## Anti-patterns
- **用体罚或责骂管教**：等于教他"不顺心就可以用暴力解决"。
- **事后很久才惩罚**：无法建立因果关联，等于无效。
- **跟2岁孩子长篇讲理**：他理解不了；用"这样你才不会受伤"级别的短句。
- **为"打人"过度反应**：会强化行为；要立即、简短、平静地制止 + 短暂隔离。
- **放任看暴力内容**：2岁看暴力节目会变得更爱攻击人。
- **拿孩子语言能力跟同龄人比较**：这一项个体差异最大，男孩普遍晚，入学时差异多消失。

## Worked Example
超市里的一次发脾气，按五步法执行：

| 步骤 | 具体动作 |
|---|---|
| 1. 预防 | 出门前说明规则；带上他可选的零食/玩具；避开疲劳与饥饿时段 |
| 2. 转移 | 情绪刚起时递上"你来帮我拿这盒牛奶"的任务 |
| 3. 命名+承认 | "你想继续玩，可我们得走了，你很生气。" 不理论、不吼、不妥协换安静 |
| 4. 带离 | 立刻离开卖场，不多解释，等他平静 |
| 5. 后续 | 平静后简短复盘："生气可以，打人/尖叫不行。" 若已打人 → 当场制止 + 短暂隔离 |

## Key Takeaways
1. "可怕的2岁"是两种冲动的拉锯，接受它比压制它更快过去。
2. 发脾气用五步法：转移 → 命名感受 → 给空间 → 公共场合带离 → 伤人行为当场隔离。
3. 词汇50个、能组2词句是2岁的语言底线；不足则查听力并做评估。
4. 他把自己当成一切事件的起因——家庭变故必须明确告诉他"这不是你的错"。
5. 规矩少而硬、作息稳定、身教大于言传，是这一年最有效的管理工具。

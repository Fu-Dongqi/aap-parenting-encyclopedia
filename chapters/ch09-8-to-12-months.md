# 第9章 8～12月龄

## Core Idea
移动能力带来第一次"身体独立"，也同时带来分离恐惧。这一阶段真正的工作是**用环境安全换探索自由**：把家彻底改成安全区，禁区越少，孩子越能自己发展。喂养上则是"手抓食物与杯子"接替"被喂"。

## Frameworks Introduced
- **"环境安全换自由"原则**：
  - 锁好危险柜门抽屉、危险与贵重物品上移、限制进入卫生间等危险房间；
  - 主动设置合法探索点：矮柜里放安全物品、包角或换软边凳、备各种靠垫当障碍；
  - 结果：家里禁区越少，你越敢放手，他越自信。
- **"该帮/不该帮"判断法**：
  - 该帮：明显沮丧而非兴致勃勃、够不到、站起来不会坐下（示范屈膝缓慢坐下而非一屁股坐地）。
  - 不该帮：为图快图干净而代劳（如一直喂饭）——剥夺了他练习的机会。
- **爬行引导法**：把有趣物品放在"差一点点够到"的位置 → 用枕头/箱子/靠垫做障碍让他翻越 → 玩藏猫猫制造动机。**绝不把孩子单独留在障碍物旁**（可能跌入枕头间无法脱身，有窒息风险）。

## Key Concepts
- **体格**：8个月男婴约8～10千克，女婴轻约220克；1岁体重约出生3倍，身高71～81厘米；头围8个月约44.5厘米、1岁约46厘米。
- **站姿与脚型**：初站时腆肚翘臀前倾、扁平足（脂肪掩盖足弓，2～3年内消失）、脚尖外偏（髋韧带松，12～18个月收紧）、仰卧时内八字（多24个月内消失）。
- **爬行**：多在7～10个月掌握；少数从不爬行（用屁股蹭或贴地挪），只要双侧协调、手脚并用即不必过度担心。
- **摔落应对**：小磕碰不可避免，平静抱起安慰两句即可；你越不惊慌，他越不害怕。
- **倒退选择**：会走之后又退回爬行是正常的——孩子总选最省力的方式。

**学步车 vs 替代品（AAP 立场）**

| 选项 | 判断 | 理由 |
|---|---|---|
| 学步车 | **强烈不建议** | 不促进走路反而削弱动机；遇玩具/地毯易翻倒；易摔下楼梯；可进入原本进不去的危险区 |
| 固定弹跳椅/游戏架 | 可用 | 无轮子，座椅可转可弹 |
| 结实四轮小车/推车 | 可用 | 须有把手且有重量，扶站时不翻倒 |

**第一双鞋的四项要求**：包头的、柔软舒适、柔韧防滑鞋底、留有脚部生长空间（运动鞋即可）。不需要特殊鞋垫、高背、鞋跟加固或足弓支撑——无证据有益，反而更难走。第一双鞋只能穿2～3个月，此后每月检查是否合脚。

## Mental Models
- **"能移动 = 必须有人看"**：一眨眼就能翻身的阶段，换尿布改在地板或大床上，绝不在高于地面的台面上操作，任何时候不独处。
- **"小物件就是毒物"**：气球碎片、纽扣电池、硬币极其危险；地板、沙发下、任何够得到的地方都不能有。
- **命名的一致性**：今天叫"猫"，明天不许改叫"咪咪"。稳定的词—物映射是他建立词汇表的前提。
- **尊重他的"词"**：他把"ma"当"奶"用，就顺着他给奶；你自己复述时说"奶"。先接受沟通意图，再修正发音。

## Anti-patterns
- **用学步车"学走路"**：无效且危险（AAP 明确反对）。
- **给学步期孩子买"矫正鞋/足弓支撑鞋"**：无证据有益。
- **为图省事继续喂饭**：剥夺自主进食与自我效能感。
- **楼梯只装一侧防护门**：上下两端都要装；即使他学会倒退下楼梯，门也要常关。
- **双语家庭担心"语言混乱"**：接触越早越易掌握；混用是阶段性正常现象。

## Worked Example
一个10个月宝宝的居家改造清单（按"风险—对策"排列）：

| 风险点 | 对策 |
|---|---|
| 楼梯 | 上下两端装儿童安全防护门，常关 |
| 柜子/抽屉 | 危险品上锁；留一个矮柜放安全物品供他"搜查" |
| 茶几/家具硬角 | 包角，或换成软边箱式凳（还能扶站） |
| 地面小物件 | 每日巡检：气球碎片、纽扣电池、硬币、纽扣 |
| 换尿布 | 撤掉尿布台，改地板或大床，全程一只手不离 |
| 站立后不会坐下 | 示范"屈膝—身体慢慢下降"，而不是一屁股坐地 |
| 走不稳常摔 | 允许小磕碰；平静安慰后放手继续 |

## Key Takeaways
1. 移动能力上线后，安全投入的回报率最高：防护门、锁、包角、撤小物件。
2. 学步车一律不用；固定弹跳椅、有重量的推拉玩具可以。
3. 第一双鞋只需"包头、柔软、防滑、留空间"，不需要矫正设计。
4. 9个月仍不能自己坐起、1岁仍不会用动作吸引注意 → 咨询儿科医生。
5. 双语越早越好；接受他的"近似词"，自己复述时用标准词。

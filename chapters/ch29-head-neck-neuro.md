# 第29章 头、颈和神经系统问题

## Core Idea
神经系统问题的判断逻辑是**"年龄越小、阈值越低"**：同样的症状在小婴儿身上可能是灾难的前兆，在大孩子身上可能只是良性现象。最典型的是脑膜炎——2个月以下婴儿的体征极其隐匿，"就医太早也比太晚好"。

## Frameworks Introduced
- **脑膜炎的年龄分层症状表**：

| 年龄 | 表现 | 判据 |
|---|---|---|
| <2个月 | 发热、食欲不振、精神萎靡、过度哭闹或烦躁 | 体征隐匿，**出现即就医** |
| 2～24个月 | 发热、呕吐、食欲不振、过度烦躁或过度困倦（烦躁可以非常夸张，睡着后很难唤醒）；伴发热的抽风可能是初始症状；出疹也可能是初始症状 | **这是脑膜炎最常见年龄段** |
| 2～5岁 | 上述症状 + 自诉头痛、背痛、颈部僵硬；**拒绝看明亮光线** | 大孩子能主诉，判断更容易 |

- **惊厥的时间阈值决策**：
  - 多数抽风自行停止，无需立即医疗；
  - 现场保护：头偏向一侧（防呕吐物误吸致窒息）；
  - **持续2～3分钟未停**，或异常严重（呼吸困难、呼吸道阻塞、脸色发青、连续多次发作）→ 拨打急救电话；
  - 不要把孩子单独留下；停止后送最近急诊室；正在服抗惊厥药者需就医调剂量。
- **先天性肌斜颈的姿势治疗（可在家做）**：
  1. 医生教一套颈部伸展训练：轻柔缓慢地把头移向歪斜的**反方向**，每天数次，随肌肉延展逐步加大幅度；
  2. 睡觉时保持仰卧，头放在与歪斜相反的位置；
  3. 清醒时把他想看的东西（窗外、床铃、图片）放在他**不常看的那一侧**，让他主动拉伸；
  4. 清醒时趴着，脸背离患侧。

## Key Concepts
- **脑膜炎**：覆盖大脑与脊髓的组织发炎。疫苗普及后**多数由病毒引起**，病毒性多不严重（3个月以下婴儿感染单纯疱疹病毒等除外），不需抗生素、恢复完全；**细菌性罕见但2岁以下风险大**，及时正确诊治时约**70%可完全康复**，约**20%**出现严重神经系统问题（耳聋、抽风、肢体瘫痪、学习障碍）。
- **易患脑膜炎的群体**：2个月以下婴儿（免疫未成熟）、经常鼻窦炎、近期严重头部损伤（颅骨骨折）、近期开颅手术、人工耳蜗植入者。
- **腰椎穿刺**：从脊髓末端下方进针抽脑脊液，避开脊髓，是安全操作。
- **晕动病**：内耳、双眼、四肢末梢感受器信息**冲突**所致（如看屏幕感到运动但身体没动；或坐低矮后排看不到窗外）。表现：胃部不适、出冷汗、疲惫、无食欲 → 呕吐；幼儿可能只表现为面色苍白、烦躁、打哈欠、哭闹。
- **腮腺炎**：病毒性，腮腺（耳前、下颌角上方）肿胀，症状持续**7～10天**；可伴关节疼痛肿胀、男孩睾丸肿胀；感染后**终生免疫**；腮腺肿胀不一定就是腮腺炎（这是"多次得腮腺炎"误解的来源）。
- **抽风 vs 癫痫**：抽风是大脑异常放电引起的短暂意识/动作/感觉/行为改变；**癫痫**是无发热等诱因下**反复**发生的抽风。约**5%**的人在儿童期出现过惊厥。
- **热性惊厥**：见于**3%～4%**的6个月～5岁儿童，最常发生在**12～18个月**；<1岁首发者复发率约50%，>1岁首发约30%；极少发展为癫痫；持续多短于1分钟，罕见可达15分钟。
- **类似抽风但并非抽风**：屏气发作、晕厥、面部或身体肌阵挛、睡眠问题（噩梦、梦游、猝倒）——这些需要完全不同的处理。
- **斜颈**：5岁以下儿童头颈歪斜最常见原因是**先天性肌斜颈**，与宫内胎位或难产（尤其臀位）有关；多在**出生后6～8周**被发现；受损肌肉为**胸锁乳突肌**（约半数可摸到小肿块），收缩致头向一侧歪、眼看向另一侧。可伴**发育性髋关节发育不良**，故常需加做髋部X线或超声。后天性斜颈多见于9～10岁以下较大儿童，常由咽喉炎症、咽痛、损伤引起，起病突然、疼痛剧烈。

## Reference Tables

**脑膜炎的疫苗防线**

| 疫苗 | 作用 | 程序 |
|---|---|---|
| B型流感嗜血杆菌（Hib） | 曾是小龄儿童细菌性脑膜炎主因 | 2、4、6个月三针 + 12～15个月第四针（部分联合疫苗不需要） |
| 肺炎球菌 | 预防脑膜炎、菌血症、肺炎 | 2个月首针，4、6、12～15个月加强；高危儿2～5岁再加一针 |
| 脑膜炎球菌（MCV4，4价结合） | 预防4种脑膜炎球菌疾病 | 不建议小婴儿，适合11～12岁或约15岁 |

**晕动病的实操要点**

| 措施 | 说明 |
|---|---|
| 停止运动 | 车上尽快安全停车、下车走动；荡秋千/旋转木马立即停下 |
| 出发前 | 若已3小时未进食，出发前给少量易消化零食（**饥饿会加重**） |
| 分散注意 | 听音乐、唱歌、聊天 |
| 看向车外 | **不在车上看书、打游戏、看屏幕** |
| 已发作 | 停车、离开安全座椅、平躺闭眼几分钟；凉毛巾敷额 |
| 预防用药 | 需先咨询儿科医生；常见副作用为困倦、口鼻干、视物模糊 |

## Mental Models
- **"小婴儿的'只是有点蔫'可能就是重症"**：精神萎靡、吃奶差、过度哭闹或异常难唤醒，在2个月以下是急诊级信号。
- **"拒绝强光 + 颈硬 + 头痛"是脑膜炎的经典三联**（2～5岁可主诉）。
- **"抽风看着像一辈子，多数只有几秒"**：家长的任务是保护现场与计时，不是制止抽搐。
- **"退热治不了惊厥"**：退热药与温水浴只能让孩子舒服，**不能预防**惊厥复发。
- **"斜颈要早治，否则面部与头型会永久变形"**：姿势治疗越早越有效，多数可免手术。

## Anti-patterns
- **等"再看看"再送医（<2个月婴儿）**：AAP 明确"早比晚好"。
- **抽风时按压肢体或往嘴里塞东西**：可能造成骨折、窒息或咬伤。
- **把屏气发作/晕厥当癫痫治**：处理完全不同。
- **靠退热药预防热性惊厥**：无效。
- **癫痫自行停药**：通常需**1～2年无发作**才考虑停药，且需医生指导。
- **只治斜颈不查髋关节**：两者常并存。
- **腮腺肿胀就断定是腮腺炎**：接种过疫苗或已患过而再次肿脸，必须就医查明真实病因。

## Worked Example
一个6周大婴儿"有点蔫、吃奶少、体温38.1℃"：

| 观察 | 判读 |
|---|---|
| 年龄6周（<2个月） | 落在我"体征隐匿"的高危区 |
| 体温38.1℃（直肠） | 超过38℃阈值 |
| 精神萎靡、吃奶减少 | 脑膜炎警示组合 |
| 决策 | **立即就医**，不做居家观察；医生可能查血、必要时腰椎穿刺 |
| 对照 | 若同样症状出现在3岁孩子身上、能玩能喝水 → 可按 Ch27 的年龄阈值分层观察 |

## Key Takeaways
1. <2个月婴儿发热+精神萎靡/吃奶差/异常哭闹 → 立即就医，不观察。
2. 脑膜炎现多以病毒为主、预后好；细菌性及时治疗70%完全康复，20%留神经后遗症。
3. 抽风侧头、计时；2～3分钟未停或脸色发青/连续发作 → 拨急救。
4. 热性惊厥见于3%～4%的6个月～5岁儿童，12～18个月最多；退热不能预防复发。
5. 先天性肌斜颈在6～8周被发现，靠"反向伸展 + 睡姿 + 引导转头"治疗，并排查髋关节发育不良。

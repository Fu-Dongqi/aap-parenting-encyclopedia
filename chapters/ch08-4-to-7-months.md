# 第8章 4～7月龄

## Core Idea
这四个月是"从躺着到坐着"的转折：翻身、手部抓握、色觉成熟、物体恒存萌芽、陌生人焦虑出现。喂养上则迎来全书的第一个硬节点——**4～6个月开始添加辅食**，且"早引入易过敏食物"比"晚引入"更能预防过敏。

## Frameworks Introduced
- **坐的四步分解**：抬头并坚持 → 手臂支撑弓背抬胸（约5个月）→ 三足鼎立（前倾+双臂支撑）→ 6～8个月可无手支撑坐一段。
- **物体恒存（Object Permanence）建立法**：4个月前"看不见=不存在"；4个月后开始相信被遮住的物体仍在。用藏猫猫、藏玩具反复验证，是这一阶段最高效的认知训练。
- **添加辅食三原则**：
  - 时机：4～6个月之间启动，6个月前仍以纯母乳为最佳；
  - 首要形态：软（安全优先）；
  - 过敏预防：**尽早**引入花生等易过敏食物（并非延后）；有严重湿疹或鸡蛋蛋白过敏者先咨询儿科医生。
- **发育健康表（红旗筛查）**：见下方参考表——本阶段最有实用价值的工具。

## Key Concepts
- **月增重**：0.45～0.56千克；约8个月达出生体重2.5倍；身高月增约5厘米、头围约2.5厘米。
- **陌生人焦虑**：5～6个月起对陌生人哭，7～8个月明显拒绝靠近的陌生人——正常发育标志，不是胆小。
- **色觉成熟**：约4个月可分辨全部颜色与深浅；此前偏爱红、蓝等高对比。
- **手部进展**：4个月可自如把东西送进嘴；6～8个月能把东西从一只手换到另一只手；约9个月出现拇食指捏取。
- **悬挂床铃的安全截止点**：孩子能撑起身体或坐直时立即取下（约5个月），防止扯落或缠住。

## Reference Tables

**发育健康表（出现以下任一情况应咨询儿科医生）**

| 类别 | 红旗信号 |
|---|---|
| 肌张力 | 看起来非常僵硬、肌肉紧张；或四肢无力像布娃娃 |
| 头部控制 | 拉着坐起时头依然向后倒 |
| 肢体使用 | 只会用一只手去够东西 |
| 社交情感 | 拒绝拥抱；对照顾者没有兴趣和感情；似乎不喜欢身边有人 |
| 眼 | 一只或两只眼持续向内/外斜视；长期流泪、泪汪汪或畏光 |
| 听觉 | 对周围声音无反应；快4个月不会扭头找声源 |
| 口腔运动 | 很难把物体送到嘴里 |
| 大运动 | 4～6个月不会翻身；快6个月扶助仍坐不稳；快7个月两腿仍无力 |
| 精细/认知 | 5～6个月不会主动够物；快7个月双眼不会跟30～180厘米的移动物体；快7个月不会用动作吸引注意 |
| 发声/互动 | 快8个月没有牙牙学语；快8个月对藏猫猫无兴趣；快5个月不会自发笑；快6个月不会笑出声或尖叫 |

**适合4～7个月的玩具**：不易碎的镜子、软球（含可发声软球）、发声布偶、易抓握的玩具、铃铛/沙铃/手鼓（确认小部件不松脱）、透明摇铃、彩色图片旧杂志、纸板书/布书/塑料书。

## Mental Models
- **"重复即学习"**：他会反复扔东西、敲打、把东西塞进嘴——每一次都在验证"我做了什么→世界怎么反应"的因果链。别把它当捣乱。
- **性格是天赋，不是作品**：活跃度、坚持度、适应性是天生气质。接受它、适配它，比"纠正"它更省力也更有效。
- **害羞的孩子不是"省心"，是需要更多**：安静、需求少的孩子容易被忽视，往往更需要主动互动与"热身时间"。
- **镜子会告诉他"那是我"**：影像与自身动作一一对应，是最早的自我识别教具。

## Anti-patterns
- **为防过敏而推迟引入鸡蛋/乳制品/大豆/花生/鱼**：无证据支持，且与当前建议相反。
- **给5个月以上婴儿继续挂床铃**：会被扯下或缠住。
- **把"扔东西"当坏行为制止**：这是因果认知实验；换成软球、软物即可。
- **强迫敏感型婴儿快速适应新环境/陌生人**：会加剧退缩，应给"旁观—热身—加入"的过渡。

## Worked Example
一位妈妈在宝宝5个半月时的判断链：

| 现象 | 判读 | 动作 |
|---|---|---|
| 会从俯卧翻到仰卧，但不会翻回来 | 正常（多数先学会俯→仰） | 不干预，继续趴卧练习 |
| 扶坐时需枕头撑腰，会前倾用双臂撑 | "三足鼎立"阶段（约5～6个月） | 提供靠垫环境，前面摆玩具吸引他保持平衡 |
| 见生人就哭，尤其7个月后 | 陌生人焦虑，正常 | 提前带孩子熟悉未来看护者；不强行让陌生人抱 |
| 盯着大人吃饭、伸手抓碗 | 辅食准备信号 | 4～6个月窗口内启动辅食；软质起步；同时引入花生类食物（无严重湿疹/蛋过敏前提下） |
| 把勺子扔地上然后看你 | 因果关系实验 | 换成软质物品，不制止 |

## Key Takeaways
1. 4～6个月启动辅食，以"软"为第一优先；易过敏食物要早引入而非推迟。
2. 坐是分解动作：抬头→肘撑抬胸→三足鼎立→独立坐，6～8个月可无支撑坐。
3. 陌生人焦虑（5～6个月起、7～8个月明显）是正常发育标志。
4. 会用整张"发育健康表"做筛查：肌张力、头控、单侧用手、眼神、发声，任一异常就问医生。
5. 孩子能撑起身体或坐直时，立刻撤掉床铃等悬挂物。

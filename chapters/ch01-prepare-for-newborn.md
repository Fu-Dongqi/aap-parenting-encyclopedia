# 第1章 为新生儿的到来做准备

## Core Idea
孕期你为胎儿能做的最有效的事，是把注意力放回自己身上——你吃下、喝下、吸入的一切几乎都会传给胎儿。妊娠期不是"为孩子做决定"的准备期，而是"为自己做决定"的执行期，且每个决定都同时作用于两个人。

## Frameworks Introduced
- **"我们的立场"（AAP Official Position）**：全书反复出现的权威表态框。遇到争议性做法（吸烟、饮酒、大麻、睡姿、襁褓）时，AAP 给的是明确立场而非"因人而异"。读法：把"我们的立场"当作默认值，把"因人而异"当作例外。
  - When to use: 家里长辈/网络说法与官方建议冲突时，先找这一框。
  - How: 定位立场 → 看它引用的证据类型（研究数据 vs 经验）→ 执行默认值，例外情况交儿科医生判断。
- **孕期致畸病原清单（TORCH 式排查）**：把"孕期生病"从笼统担忧拆成可预防的具体条目。
  - 风疹（孕前20周风险最高，孕前查抗体、产后补种，孕期不能接种）
  - 水痘（孕前接种；孕晚期感染极危险）
  - 疱疹（产道感染→新生儿水疱、脑炎；临产有症状→剖宫产）
  - 弓形虫（猫粪、生肉、未洗蔬果；换猫砂戴手套）
  - 寨卡（蚊媒+性传播，无疫苗）
  - 李斯特菌（未经巴氏消毒奶制品、冷切肉、烟熏海鲜）
  - 流感（孕妈接种流感疫苗保护6个月内婴儿）
  - 百日咳/白喉/破伤风（孕27～36周接种百白破，把抗体经胎盘传给宝宝）

## Key Concepts
- **叶酸**：B族维生素，降低脊柱裂等神经管缺陷风险，孕期每天约400微克。
- **DHA/ARA**："好"脂肪酸，胎儿大脑与眼睛发育（尤其孕末3个月）大量需要，母乳中也有。
- **延迟脐带结扎**：健康新生儿出生后等30～60秒再断脐。
- **百白破疫苗（Tdap）孕期接种窗口**：孕27～36周，也给所有将密切接触宝宝的人（父亲、祖父母、保姆）接种。
- **汞含量高的鱼**：鲨鱼、箭鱼、国王鲭、马头鱼——孕妇与儿童尽量避开。
- **低汞优选**：虾、罐装淡金枪鱼、鲑鱼、鳕鱼、鲶鱼（长鳍金枪鱼汞偏高）。

## Mental Models
- **"两个人吃"不是"吃两人份"**：增量在质量不在热量。缺营养会伤胎儿，但妊娠期不是减重或低热量饮食的时机。
- **把"风险"换算成"每周上限"**：模糊的"少吃"无法执行，AAP 给的是可计量上限——鱼227～340克/周、本地野鱼单周≤170克且当周不再吃其他水产、咖啡因≤200毫克/天。
- **疫苗是给新生儿的"产前保险"**：6个月内婴儿无法接种多数疫苗，母亲孕期接种是唯一能提前建立保护的通道。

## Anti-patterns
- **"孕期补品多多益善"**：高剂量维生素A已知会致新生儿先天异常；任何药物/补充剂（含"纯天然"标签）都要先问医生。
- **"只戒到生完"**：吸烟的家庭环境增高婴儿猝死综合征、中耳炎、呼吸道疾病与日后肥胖风险，需永久戒烟。
- **"孕期接种风疹疫苗"**：孕期禁用，只能孕前或产后补种。
- **"自己判断鱼类安全"**：无本地鱼类食用建议时，按 AAP 上限执行，而不是凭感觉。

## Worked Example
一位孕28周的准妈妈列"要不要做的事"清单，按本章框架逐项判定：

| 事项 | 判定 | 依据 |
|---|---|---|
| 接种百白破 | 现在就打 | 孕27～36周窗口内，越早越好 |
| 接种流感疫苗 | 打（流感季） | 保护6个月内婴儿 |
| 接种风疹疫苗 | 不打，产后再补 | 孕期禁用活疫苗 |
| 吃三文鱼/鳕鱼 | 每周2～3顿 | 低汞、富ω-3 |
| 吃生鱼片 | 不吃 | 寄生虫风险，需烹熟或冷冻 |
| 每天2杯咖啡 | 临界，建议减 | ≤200毫克/天属未证实有风险，但应限制 |
| 清理猫砂 | 让别人做，或戴手套+洗手 | 弓形虫 |
| 装修婴儿房 | 可以，但全程通风，新家具先通风再用 | 挥发性化学物质 |

产前还需与医生确认三件事：宝宝何时可以出院、是否做包皮环切、是否储存脐带血。

## Key Takeaways
1. 叶酸400微克/天、DHA/ARA 是孕期最值得盯的两项营养，别把精力花在"多吃"上。
2. 孕27～36周接种百白破，是保护新生儿前6个月的关键动作；同住者也要查疫苗效力。
3. 孕期用药一律先问医生，包括感冒药、抗组胺药、"纯天然"补充剂。
4. 感染预防比治疗重要：风疹/水痘靠孕前疫苗，弓形虫/李斯特菌靠饮食与卫生习惯。
5. 分娩前就把"出院时机、包皮环切、脐带血"三个决定做完，别留到产房里临时想。

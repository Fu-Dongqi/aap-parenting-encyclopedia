# 第7章 1～3月龄

## Core Idea
这三个月的主线是"反射退场、自主动作登场"，最值得盯的一项能力是**颈部控制**——它是一切后续运动（翻身、坐、爬、走）的地基。同时，这是孩子第一次用"社交性微笑"把父母变成主动的交流伙伴。

## Frameworks Introduced
- **趴卧练习（Tummy Time）作为发育引擎**：
  - 出生起每天趴几次（清醒+看护）；
  - 不到2个月：挣扎抬头一两秒；
  - 快4个月：用肘撑起头部和胸部；
  - 附带收益：检查听力和视力（用玩具在前方吸引他抬头看）。
- **生长速率优先于绝对数值**：每月体重增0.7～0.9千克、身高2.5～4厘米、头围1.25厘米；判断标准是"是否沿着自己的曲线走"，不是"是否达到平均值"。
- **发育的"平台—飞跃"节律**：几周安睡整夜后突然频繁夜醒，往往预示一次发育飞跃；1～2周后恢复且白天小睡次数减少、单次变长。

## Key Concepts
- **社交性微笑**：满月后出现，是真正意义上的交流笑容（之前的笑多为反射性或睡眠中的笑）。
- **后囟门闭合**：约3个月时。
- **惊跳反射与强直性颈部反射**：2～3个月间逐渐消失（详见 Ch6）。
- **俯卧→仰卧翻身**：快4个月可出现（仰卧→俯卧约6个月）。
- **色觉**：约4个月才完全成熟，此前对亮度/对比度更敏感，所以柔和婴儿房配色并不吸引他。
- **咿呀学语**：约2个月出现重复元音（"啊啊""哦哦"）。

## Reference Tables

**1～3月龄发育里程碑**

| 维度 | 表现 |
|---|---|
| 运动 | 俯卧可抬头抬胸、用前臂撑起上半身；双腿伸展可踢；双手张开又合拢；脚触硬平面会下蹲；手可放进嘴里；能摆弄面前悬挂物；能抓小玩具并摇晃 |
| 视觉 | 认真观察人脸；视线可跟踪移动物体；能辨认一定距离内熟悉的人与物；手眼开始协调 |
| 听觉语言 | 听到你的声音会笑；开始牙牙学语；模仿一些声音；听到声音会转头找声源 |
| 情感社交 | 出现社交性微笑；喜欢与人玩、游戏停止会哭；表情与身体语言更丰富；会模仿动作和表情 |

## Mental Models
- **"先抬头，才有后面的一切"**：颈部控制 → 肘撑 → 翻身 → 坐 → 爬。别跳过前一步去催后一步。
- **用"高音调、慢速、夸张口型"跟婴儿说话**：这不是幼稚，是符合婴儿听觉偏好的有效输入；但要有意识逐步加入成人用语并淘汰儿语。
- **把镜子当教具**：镜子里的影像随他自己的动作变化，这是最早的"自我认知"实验。
- **抱孩子时永远扶头**（3个月前无法自己竖头），但突然移动或施力时更要扶。

## Anti-patterns
- **用学步车/弹跳架替代趴卧**：违背发育顺序，且学步车有翻倒风险（AAP 明确反对，见 Ch9）。
- **担心"竖抱弹跳伤腿"**：3～4个月托着腋下让他蹬地、弹跳是安全的，且有益。
- **把"发育停滞"当退步**：平台期后通常跟着飞跃，别在这时加训练量。
- **只看单项里程碑**：一两个月的差异属正常范围，看趋势与整体。

## Worked Example
一位爸爸在宝宝10周时的四项观察与结论：

| 观察 | 判读 |
|---|---|
| 俯卧时能抬头约3秒，随即放下 | 正常（<2个月的表现），继续每天多次短时练习 |
| 竖抱时头会突然向后倒 | 正常（3个月前不能自主竖头），务必持续扶头 |
| 视线能跟着摇铃左右移动约90° | 正常；目标是3个月时达180° |
| 看到妈妈的脸会笑并发出"啊啊"声 | 社交性微笑 + 咿呀学语，两项都在轨 |

若到3个月仍无法双眼同时跟踪物体，或快4个月仍不会扭头找声源 → 与儿科医生讨论（可能涉及视力或听力）。

## Key Takeaways
1. 每天多次趴卧练习，目标是4个月时能用肘撑起头胸。
2. 生长看"月增量 + 自己曲线的斜率"：0.7～0.9千克/月、2.5～4厘米/月、头围1.25厘米/月。
3. 3个月前竖抱必须扶头；3～4个月可托腋下让他蹬地弹跳。
4. 社交性微笑与咿呀学语是这一阶段最重要的两个"软指标"。
5. 夜醒突然增多常是发育飞跃的前兆，先观察1～2周再调整作息。

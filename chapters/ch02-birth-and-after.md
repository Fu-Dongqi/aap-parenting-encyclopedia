# 第2章 分娩和分娩后

## Core Idea
分娩后第一个小时是"黄金1小时"——新生儿的机敏度、觅食反射和母亲的射乳反射同时达到峰值。分娩方式可以不同，但这60分钟的肌肤接触与首次哺乳，是本章唯一不可让渡的核心动作。

## Frameworks Introduced
- **黄金1小时（肌肤接触+首次哺乳）**：出生后1小时内母婴肌肤接触并开始哺乳。
  - When to use: 无论自然分娩还是剖宫产，只要母婴情况稳定。
  - How: 擦干保暖、戴帽子、盖毯 → 放胸前 → 让宝宝自行向乳房挪动含乳 → 不急着洗澡/清洗 → 1小时后再做身高体重与用药。
  - Why it works: 稳定新生儿血糖与体温、减少哭闹、稳定呼吸与血流；母亲侧可减少产后出血。宝宝靠气味与感觉找到第一口奶。
- **阿氏评分（Apgar Score）**：出生后1分钟和5分钟各评一次，5项体征各0～2分。
  - 五项：心率、呼吸、肌张力、对刺激的反应、肤色。
  - 读法：7分以上常见（手脚发青扣分），满分10分很少；它只说明"此刻需要什么帮助"，**不能预测**未来健康、智力或性格。
- **TOLAC（剖宫产术后阴道试产）**：既往剖宫产者并非必须再剖，多数人可尝试试产，需与医生共同决策。

## Key Concepts
- **足月范围**：孕37～42周分娩。
- **宫口开全**：直径约10厘米。
- **延迟脐带结扎**：健康新生儿等30～60秒断脐；脐带无神经，剪断不痛。
- **脐带夹**：保留24～48小时或至干燥不出血；残端1～3周自然脱落。
- **初乳**：产后2～5天分泌，淡黄、量少、富蛋白与抗体，足以满足头几日全部养分与水分需求。
- **新生儿呼吸频率**：40～60次/分，短促表浅、偶夹一次深呼吸（成人12～14次/分）——正常。
- **维生素K注射**：所有新生儿出生后即注0.5～1毫克，预防新生儿出血症（缺乏可致脑损伤甚至死亡）。
- **CPAP（持续气道正压通气）**：新生儿呼吸费力时的首选无创支持；无效则气管插管+脐带给药。
- **臀位**：约每100个新生儿中3个；确诊靠超声，通常建议剖宫产。

## Mental Models
- **把分娩当成"有预案的流程"而非"事件"**：剖宫产率约1/3，常见指征有限且明确（剖宫产史、臀位、宫口不扩张、胎心异常、医生判断阴道分娩有风险）。预案要覆盖"如果转剖"。
- **"敏感期"是一次性窗口**：出生后几小时的反应度极高，之后迅速回落。错过不是灾难，但不可重来。
- **建立亲密关系没有倒计时**：没有立刻产生温馨感、或宝宝被送进育婴室，都不会损害亲子关系——这条要用来安抚焦虑，而不是用来放松执行。

## Anti-patterns
- **出生后急着洗澡/清洗**：会冲掉宝宝寻找乳头所依赖的气味线索。
- **把阿氏评分当成"体检成绩"**：它是适应性评估，不是发育预测。
- **全麻剖宫产后强行立刻哺乳**：母亲可能昏睡数小时，等清醒有力气再做，不必自责。
- **把"没有立刻爱上孩子"当异常**：产后第一反应常常只是解脱与疲惫，属正常。

## Worked Example
一位计划自然分娩的初产妇，把产后流程按时间轴排好：

| 时间 | 做什么 | 为什么 |
|---|---|---|
| 出生即刻 | 延迟断脐30～60秒，放母亲下腹 | 增加血容量与铁储备 |
| 0～1小时 | 肌肤接触、戴帽盖毯、尝试含乳 | 黄金1小时，觅食反射最强 |
| 1小时内 | 医护完成阿氏评分（1分钟、5分钟） | 评估适应性，不打断接触 |
| 1小时后 | 测身高体重、注射维生素K 0.5～1mg、眼部预防用药 | 预防出血症与产道细菌眼部感染 |
| 产后2～5天 | 初乳分泌，按需哺乳8～12次/24h | 建立泌乳 |
| 出院前 | 确认能识别"吃到奶"的迹象 | 避免回家后喂养失败 |

若中途转剖宫产：改为先确认麻醉方式（优先腰麻/硬膜外，保持清醒）→ 提前问清医院肌肤接触规定 → 术后母子同室、持续哺乳。

## Key Takeaways
1. 出生后1小时内的肌肤接触与首次哺乳，优先于一切清洁与流程。
2. 所有新生儿都要注射维生素K（0.5～1毫克），这是防脑损伤的硬性动作。
3. 阿氏评分7分以上常见、10分罕见，它不预测未来——别拿它吓自己。
4. 剖宫产率约1/3，指征清晰；有剖宫产史者可讨论TOLAC。
5. 新生儿呼吸40～60次/分、手脚发青、胎头变长都是正常过渡现象。

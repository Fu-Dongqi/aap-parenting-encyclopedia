# 第17章 哮喘和过敏

## Core Idea
哮喘不可治愈但可控，且控制的核心不是"发作时救急"，而是**每天的抗炎维持 + 诱因清除**。本章最值得背下来的是那个"交通信号灯"行动计划：绿、黄、红三档，各自对应明确的动作。

## Frameworks Introduced
- **哮喘诊断的"3次法则"**：孩子出现**3次或以上哮鸣发作**后，医生一般即可确诊哮喘。若1岁内起病且反复发作，可确诊。
  - 反之：无其他过敏性疾病、父母无哮喘、长大不再因频繁感冒诱发哮鸣 → 哮鸣可在3～6岁逐渐好转。
- **哮喘行动计划（红黄绿灯）**——必须书面、与医生共同制订：
  - **绿灯**：日常维持，保持健康每天做什么（含控制药）。
  - **黄灯**：出现轻度症状时做什么（急救药 + 观察 + 何时联系医生）。
  - **红灯**：中度/重度发作时做什么（急救药 + 立即就医/急诊）。
- **两药分工模型**（这一章最容易混淆的地方）：

| 类别 | 代表 | 作用 | 使用时机 |
|---|---|---|---|
| 快速缓解药/急救药 | 沙丁胺醇 | 扩张气管、放松平滑肌，缓解症状数小时 | **发作时按需**；不能解决根本问题 |
| 控制性/维持性药物 | 吸入性皮质激素、白三烯受体拮抗剂 | 治疗气道炎症、降低敏感度 | **每天使用**；通常需连续用药才见效 |

- **"控制药启动门槛"**：满足任一即应使用控制性药物——1周内症状发作≥2次；每月≥2次因夜间症状醒来；1年内需口服皮质激素≥2个疗程；曾因哮喘住院。

## Key Concepts
- **哮鸣**：呼气时的高音调声，由细支气管狭窄（多因炎症）所致；夜间或清晨更明显。**但并非所有哮鸣都是哮喘**。
- **哮喘加重时哮鸣反而可能减轻**：因为进出肺的气体都变少了——这是危险信号而非好转。
- **辅助呼吸肌收缩**：用力呼吸时肋间与颈部肌肉凹陷。
- **间隔装置/储雾罐**：按压式吸入器必配，让药雾扩散直达肺部细支气管；无它则大部分药沉积在咽后部被吞下。
- **吸药后漱口或刷牙**：吸入性皮质激素对肺有益，对牙齿有害。
- **雾化 vs 按压式**：两者同样有效；急救药经雾化吸入剂量通常远大于按压式2喷。
- **哭闹会显著减少到达肺部的药量**：不哭时给药最理想。
- **电子烟对哮喘儿童尤其危险**：排放物含尼古丁及刺激性、致炎、致癌化学物。

## Reference Tables

**常见哮喘诱因**

| 类别 | 具体 |
|---|---|
| 刺激物（对所有人都危险） | 烟草烟雾（最重要）、电子烟、烧火与焚香、气味强烈的清洁剂、杀虫喷雾、油漆、空气清新剂、香水、户外空气污染、冷空气 |
| 过敏原（仅对过敏者） | 尘螨（床品浓度高）、蟑螂、动物皮屑、树木/草花粉、霉菌与孢子 |
| 感染 | 病毒性上呼吸道感染、普通感冒（幼儿最常见诱因） |
| 其他 | 压力与情绪低落、鼻窦感染、非甾体消炎药（布洛芬、阿司匹林）敏感 |

**家庭防尘螨清单（可直接照做）**

- 用专用防过敏原床罩包裹床垫与枕头；
- 枕头、被子选可机洗款；
- 每周用**热水**清洗床单、毯子、枕套、抱枕、毛绒玩具；
- 尽量不在孩子房间放毛绒玩具；
- 不让宠物进入孩子房间；孩子过敏则考虑送走宠物；
- 吸尘、掸灰时让孩子离开家中；
- 可配 HEPA 空气过滤器；
- 室内湿度控制在**50%以下**（尘螨与霉菌喜潮）；
- 不用香水与带香味的清洁剂；
- 修理漏水管道；家中与车内绝对禁烟。

**儿童湿疹（特应性皮炎）三期**

| 期 | 年龄 | 典型部位与表现 |
|---|---|---|
| 婴儿期 | 几周～6个月 | 脸颊、额头、头皮瘙痒发红、小丘疹，可扩散至躯干四肢；**剧烈瘙痒是突出特征**；多数2～3岁好转 |
| 儿童期 | 4～10岁 | 肘窝、膝窝，有时手腕背面、脚踝外侧；红色鳞屑斑，因抓挠而干燥、结痂、发炎；久之色素加深变厚 |
| 青少年/成年期 | 12岁以上 | 瘙痒、干燥、起皮，可持续到成年 |

**接触性皮炎的两类来源**

- 刺激性：柑橘等酸性物质、泡泡浴、强碱性肥皂、羊毛或粗糙织物、**孩子自己的口水**（流口水/舔嘴唇→口周湿疹）。
- 过敏性：镍制首饰与牛仔裤扣、牙膏/漱口水中的调味剂或添加剂、制鞋胶水与染料及皮革、衣物染料、毒葛/毒橡树/毒漆树（接触后1～3天出疹）、抗生素与抗菌软膏。

## Mental Models
- **"控制药是存款，急救药是取现"**：只取不存，迟早透支。日常不用控制药而频繁用急救药，是失败模式。
- **"哮喘控制良好的孩子可以照常运动"**：运动后咳嗽哮鸣是控制不佳的信号，不是禁止运动的理由。
- **"停药是最常见的失败原因"**：感觉良好时也要用；把用药绑在固定习惯上（如刷牙前）。
- **"湿疹的敌人是干和痒，不是脏"**：过度清洁与热水反而加重；关键是保湿与止痒、避免诱因。

## Anti-patterns
- **把"哮鸣减轻"当好转**：可能是气流进一步受限。
- **急救药当日常药天天用**：说明控制不足，需上调控制治疗。
- **擅自减量、停药、换药**：必须在医生指导下逐步减量。
- **用按压式吸入器不加间隔装置**：药到不了肺。
- **吸药后不漱口**：皮质激素损伤牙齿。
- **家里有人吸烟但"不在孩子面前抽"**：烟雾残留仍会暴露，且降低控制药疗效；最有效的措施是戒烟。
- **用止咳药对付哮喘性咳嗽**：AAP 立场是6岁以下儿童非处方止咳药无效且有严重副作用风险。

## Worked Example
一个5岁哮喘男孩的绿黄红三档计划（书面贴在冰箱上）：

| 档位 | 判断依据 | 动作 |
|---|---|---|
| 绿 | 无咳嗽哮鸣、夜间安睡、能正常跑跳 | 每天吸入性皮质激素（刷牙前）+ 每周热水洗床品 + 家中车内禁烟 |
| 黄 | 夜间咳嗽、运动后哮鸣、感冒后加重 | 按需沙丁胺醇；继续控制药；48小时无改善或每周急救药>2次 → 联系医生 |
| 红 | 呼吸急促且吸气时胸壁凹陷、呼气有咕噜声、嘴唇/指尖发青、烦躁困倦神志不清、呼吸时胸痛 | 立即用急救药并**即刻急诊**；反复呕吐无法口服药或补液、无法说话或入睡同样立即就医 |

## Key Takeaways
1. 3次以上哮鸣发作即可考虑哮喘诊断；1岁内起病且反复者更明确。
2. 急救药（沙丁胺醇）只管几小时，控制药（吸入性皮质激素）才是根本，必须每天用。
3. 控制药启动门槛：每周症状≥2次、每月夜醒≥2次、年口服激素≥2疗程、或曾住院。
4. 按压式吸入器必配储雾罐，吸后漱口/刷牙；哭闹时给药效果差。
5. 湿疹分三期，婴儿期以脸颊头皮剧烈瘙痒为特征；接触性皮炎常来自口水、镍扣、鞋胶与染料。

# 第13章 4～5岁

## Core Idea
4岁常被误认为"可怕的2岁回来了"：他变成不知疲倦、霸道好斗的"永动机"，情绪一秒切换，执着于固定规律。但这是**从想象世界走向现实世界的过渡期**。到5岁，他会明显沉稳自信，具备进入正规学校的能力。

## Frameworks Introduced
- **"接触式看护"（Touch Supervision）**：这条规则针对水边，是本阶段最硬的生死线。
  - 孩子在水中时，成年人必须在**一臂之内**；
  - 绝对不让孩子在任何水域（泳池、温泉、湖泊、大海、浴缸）附近独处，哪怕一会儿；
  - 避免手机等让人分心的物品；
  - 理由：4～5岁即使会游泳也游不好、游不久；一旦轻微下沉，恐慌会让他忘记如何上浮。
- **"人与行为分开"的管教法**：
  - 惩罚针对"他做的某件事/说的某句话"，而非"他是坏孩子"；
  - 不说"你怎么这么坏"，改为具体解释他做错了什么；
  - 非故意的错误要安慰并明确"我知道你不是故意的"。
  - 原因：这一年龄的道德观极简单，**后果代表一切，意图不重要**——打碎贵重物品时他会觉得自己很坏，即使纯属意外。他需要学会区分"意外犯错"与"故意犯错"。
- **阅读的"兴趣优先"原则**：
  - 提前识字带来的优势，到小学二三年级会消失（其他孩子自然追上）；
  - 决定学业成绩的最重要因素不是提前学了多少，而是**对学习的兴趣**；
  - 做法：不强迫认字，提供有趣的学习机会，陪他一起用工具（电视节目、电子游戏都要共同参与并匹配难度）。

## Key Concepts
- **运动能力接近成人**：单脚站10秒以上、双脚交替上下楼梯不用扶手、翻跟头、立定跳远、自己发力荡秋千。
- **判断力落后于运动能力**：他会远远跑在前面，过马路必须牵手。
- **词汇量**：4岁约1500词，4～5岁再增约1000词；能讲有情节的复杂故事。
- **发音**：4岁可准确发出大部分音；f/v/s/z 约5.5岁掌握，sh/l/th/r 需6岁后。
- **粗话现象**：他发现语言的"力量"，用它观察大人反应；处理靠榜样 + 冷静不关注 + 幽默化解。
- **暴力想象游戏**：战争游戏、手指当枪、追逐打闹不代表暴力倾向——他不理解死亡与杀戮，这只是娱乐与自我认同。
- **"最好的朋友"**：开始有明确偏爱，朋友开始影响他的想法与行为。

## Mental Models
- **"挑战权威是独立性的健康信号"**：他第一次对你粗鲁，说明他在检验独立程度。反应越情绪化，越强化不良行为。
- **"规矩他遵守，往往因为怕罚，不是因为认同"**：所以道德教育要靠"人与行为分开"的解释，而不是靠加重量罚。
- **"幽默优于对抗"**：他说你是"老巫婆"，你回"老巫婆正在用蝙蝠翅膀和青蛙眼睛煮汤，你想吃吗？"——既化解又保住关系。
- **"伤人的话是情绪的替代品"**：他说"我恨你"，真实意思是"我现在很生气，帮我摆脱这种心情"。发火只会让他更不知所措。

## Anti-patterns
- **强迫4岁孩子提前识字**：短期"优势"很快消失，代价是厌学。
- **因孩子玩"枪战游戏"紧张**：禁玩具枪只会让他用纸壳做枪；这阶段与暴力倾向无关。
- **在孩子说粗话时大反应**：等于给他想要的关注。
- **只教"对不起"不解释原因**：无法改变行为。
- **让孩子在水边"就一会儿"独处**：溺水风险最高的一类疏忽。
- **把"瘦"当营养不良**：身高增速与肌肉增速不同步是常见现象。

## Worked Example
一个4岁半孩子在游乐场推倒了同伴，按"人与行为分开"处理：

| 步骤 | 说法/动作 |
|---|---|
| 1. 立即制止 | 蹲下平视："停。不能推人。"（简短，不训话） |
| 2. 关注受伤方 | 先看被推的孩子，让他看到"别人会疼" |
| 3. 分清人/行为 | "你是个好孩子，但推人这件事不可以。"（不说"你怎么这么坏"） |
| 4. 归因与修复 | "你是想玩那个滑梯对吗？下次可以说'轮到我了'。现在去问他要不要一起玩。" |
| 5. 事后强化 | 当天他做到轮流时立刻表扬，强化正确路径 |

## Key Takeaways
1. 水域安全用"一臂之内"的接触式看护，任何水域都不例外。
2. 惩罚对"行为"不对"人"；这一年龄他看后果不看意图，必须教他区分意外与故意。
3. 4岁1500词、能讲有情节的故事；f/v/s/z 到5.5岁、sh/l/th/r 到6岁后才准。
4. 不强迫提前识字；保护学习兴趣比抢跑更重要，抢跑优势到小学二三年级消失。
5. 粗话与"我恨你"用冷静 + 幽默 + 情绪命名处理，反应越大越强化。

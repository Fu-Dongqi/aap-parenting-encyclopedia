# 第27章 发热

## Core Idea
发热是症状，不是疾病——它是身体对抗感染的**积极行为**（刺激白细胞攻击病原体）。因此本章的核心不是"把温度压下去"，而是**按年龄与精神状态分层决策**：什么时候必须就医，什么时候只需观察。

## Frameworks Introduced
- **年龄分层就医阈值（本章最硬的三条数）**：

| 年龄 | 阈值 | 动作 |
|---|---|---|
| ≤2个月 | 直肠 ≥38℃（腋下 >37.2℃） | **立即就医**（排除严重感染，此期体征隐匿） |
| 3～6个月 | ≥38.3℃ | 就医 |
| >6个月 | ≥39.4℃ | 就医 |
| >1岁 | 饮食睡眠良好、有精神玩耍 | 一般不必立即就医；但高热持续**>24小时**即使无其他不适也应就诊 |

- **精神状态优先于温度数值**：比起发热的度数，**孩子的精神状况是更主要的提示**。烦躁不安或异常困倦、皮疹、咽痛、耳痛、咳嗽、反复呕吐腹泻 → 联系医生。
- **热性惊厥处置五条**：
  1. 把孩子放在地板或床上，远离坚硬尖锐物；
  2. 头转向一侧，让口水或呕吐物能流出；
  3. **不往嘴里放任何东西**（他不会咬伤自己的舌头）；
  4. 看儿科医生；
  5. **惊厥持续超过15分钟 → 拨打急救电话**。

## Key Concepts
- **体温的正常波动**：婴儿体温高于年长儿；午后至傍晚最高，午夜至清晨最低。
- **测量部位与阈值**：直肠/口腔/耳/颞动脉以38℃为界；**腋下临界值较低，为37.2℃**。直肠测温是婴儿（尤其3个月以下）的"金标准"。**摸额头或用测温条不准确**（打冷战时不准确）。
- **体温计选择**：AAP 不再建议水银体温计（破碎后汞挥发可致中毒）；推荐电子体温计；耳温枪受耳垢与外耳道弯曲影响；额温枪（颞动脉）操作简单、睡着也能用。
- **热性惊厥**：见于6个月～5岁，多在发热最初几小时内发生；常有家族聚集；持续通常不超过1分钟（少数可达15分钟）；**几乎无危害**，不引起脑损伤、瘫痪、智力障碍或死亡。
- **复发概率**：<1岁首次发作 → 约50%再发；>1岁首次 → 约30%；24小时内很少发作超过1次。
- **关键反常识**：**积极退热不能预防热性惊厥复发**——不要因为曾有惊厥就采用极端方式降温。
- **中暑 ≠ 感染性发热**：由环境过热引起（海滩、密闭汽车、穿太多），体温可>40.5℃，属**急症**，需脱衣、凉水擦拭、扇风、移至阴凉处，重度须急救。

## Reference Tables

**退热药使用边界**

| 药物 | 最小年龄 | 频次上限 | 禁忌与注意 |
|---|---|---|---|
| 对乙酰氨基酚 | 3个月 | 每4小时1次，24小时内≤5次 | 肝病者需问医生；过量可致肝中毒（恶心、呕吐、腹部不适） |
| 布洛芬 | 6个月 | 每6～8小时1次，24小时内≤4次 | **脱水或持续呕吐时须遵医嘱**（肾损伤风险）；肾病、溃疡或其他慢性病先问医生 |
| 阿司匹林 | — | — | **儿童发热一律不用**（瑞氏综合征） |

**核心原则**：剂量按**体重**计算，而非按年龄（年龄剂量表仅为方便）；只用该药配套的量具；注意复方感冒药/止咳药里也可能含对乙酰氨基酚，叠加会超量。

## Mental Models
- **"发热是消防演习，不是火灾"**：适度发热帮助对抗感染；是否用药看孩子是否**明显不舒服**，而不是看数字。
- **"年龄决定风险，精神决定紧急"**：小月龄 + 高热 = 高风险；大孩子 + 高热但能玩能喝 = 可观察。
- **"温度计不是诊断工具"**：它只告诉你有没有发热，病因与严重程度要靠年龄、精神、伴随症状判断。
- **"惊厥看着可怕，预后多良好"**：家长最需要做的是保护现场安全、侧头、计时。

## Anti-patterns
- **靠摸额头判断发热**：不准确，尤其打冷战或环境温度影响时。
- **给儿童用阿司匹林退热**：瑞氏综合征。
- **对乙酰氨基酚与含同成分的复方感冒药同服**：叠加超量、肝损伤。
- **为防惊厥而过度降温（冰浴、酒精擦浴）**：无效且有害。
- **惊厥时往嘴里塞勺子/手指**：可能造成伤害，且他并不会咬伤舌头。
- **把中暑当感染性发热处理**：中暑是急症，需物理降温 + 急救。
- **孩子高热但精神好就完全不就医**：>24小时高热即便无其他症状也应就诊。

## Worked Example
两个同样38.8℃的孩子，处置完全不同：

| 项目 | A：3个月婴儿 | B：3岁幼儿 |
|---|---|---|
| 阈值 | 3～6个月 ≥38.3℃ 即就医 | >6个月阈值39.4℃；且>1岁可先观察 |
| 精神 | 吃奶差、嗜睡 | 能喝水、能玩一会儿 |
| 决策 | **当日就医**（小月龄体征隐匿） | 居家观察：补液、按体重给对乙酰氨基酚、每4小时复测 |
| 观察窗 | 由医生判断 | 若高热持续>24小时，或出现皮疹/耳痛/呕吐腹泻/异常困倦 → 就诊 |
| 若发生惊厥 | 侧头、计时、不塞物、就医；>15分钟拨急救 | 同左 |

## Key Takeaways
1. 三条年龄阈值：≤2月≥38℃立即就医；3～6月≥38.3℃；>6月≥39.4℃。
2. 精神状态比温度更重要；>1岁高热持续>24小时也应就诊。
3. 对乙酰氨基酚≥3个月、布洛芬≥6个月；儿童一律不用阿司匹林；剂量按体重算。
4. 热性惊厥几乎无害：侧头、计时、不塞物；>15分钟拨急救；退热不能预防复发。
5. 中暑体温可>40.5℃，是急症，靠物理降温与急救，不是退热药。

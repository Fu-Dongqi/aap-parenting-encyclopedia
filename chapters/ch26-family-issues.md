# 第26章 家庭问题

## Core Idea
家庭结构的变化（收养、离婚、再婚、多胞胎）本身不决定孩子的结局，决定结局的是**父母能否合作满足孩子的情感需要**，以及**孩子是否被错误地归因**（把大人的事算在自己头上）。这一章最实用的部分，是那张"虐待的体征清单"。

## Frameworks Introduced
- **离婚反应的年龄分层（按年龄预判，别按年龄定罪）**：
  - **2岁以下**：退行到婴儿行为——异常粘人、依赖、沮丧；拒睡或夜醒。
  - **3岁以下**：悲伤、怕人；发脾气、食欲不振、如厕训练倒退。
  - **3～5岁**：也可能表现得像婴儿；**认为父母的离婚是自己造成的**（此年龄无法理解"父母的生活与自己的生活是分开的"，认为自己是家庭中心）。可能更具攻击性、对父母一方很不友好。与非监护方接触越少，反应越严重。
  - 共性：手续办理期与刚离婚时反应最激烈；节日、生日、家庭聚会时尤其痛苦；**反复分分合合比一次性离婚伤害更大**。
- **帮助离婚家庭孩子的三条**：
  1. 坦诚相待，但不伪装"父母仍相爱"；让他相信父母双方都仍一样爱他；
  2. 不在他面前争吵、不让他听到自己的名字出现在争吵中（否则更确信"是我造成的"）；
  3. 更努力地爱他、让他安心；重视他的感受，他就能更好地从不确定与焦虑中恢复。
- **虐待的识别框架（身体迹象 + 行为变化，组合判断）**：
  - 儿童虐待分四类：身体虐待、性虐待、忽视（生理/情感/医疗/教育/监护）、心理或情感虐待（含言语虐待）。
  - 关键判据是**"解释不匹配"**：损伤与描述不符、与孩子运动能力不符。

## Key Concepts
- **收养告知原则**：在孩子能理解时（约2～4岁）就让他知道，按成熟度给信息。示例表述："你的生父母非常爱你，但他们知道自己无法照顾你，所以找到了很喜欢孩子、想有更大的人家来照顾你。" 他长大问更具体的问题时诚实回答；他不舒服或不想听时不强加。
- **"被收养的故事属于孩子"**：对外人诚实但按情境控制细节；敏感细节保密到孩子能自己决定"如何、向谁"分享。
- **虐待的流行病学（美国数据）**：每年约400万件可疑报告，涉及约700万儿童；受害者最多的是婴儿，**25%的受害者不到3岁**；约每20个孩子有1个遭身体虐待；约1/5女孩、1/20男孩在18岁前遭性虐待；**超过90%的性虐待受害者认识施虐者**，且多数发生在家庭中。
- **虐待的危险因素**：父母抑郁或其他精神问题、父母童年期曾受虐待、父母吸毒、家庭暴力；贫困家庭、未成年父母、酗酒家庭中忽视与虐待更常见。
- **长期后果**：精神伤害大于身体伤害；可致抑郁、恐惧、自杀或暴力行为、学习障碍、吸毒酗酒、离家出走、成年后婚姻与性障碍、犯罪。**年龄越小、持续时间越长、与施虐者关系越亲密，后果越严重**；与一位支持他的成年人建立亲密关系可显著提高韧性。

## Reference Tables

**虐待的身体迹象**

| 迹象 | 说明 |
|---|---|
| 还不会翻身的婴儿出现的任何损伤 | 与其运动能力不符 |
| 4岁以下儿童的躯干、耳朵或脖子有淤青 | 这些部位极难由意外造成 |
| 损伤与描述不符/无法充分解释/与运动能力不符 | 包括淤青、烧烫伤、骨折、胸腹或头部损伤 |
| 体重不增（尤其婴儿期）或突然显著增加 | — |
| 非医学原因的头痛或腹痛 | — |
| 外生殖器疼痛、出血或分泌物 | 需排查性虐待 |
| 感染性传播疾病 | 强提示 |

**提示虐待的行为与心理变化**（非特异，需结合情境调查）

- 恐惧行为（噩梦、抑郁、异常害怕）
- 已完成如厕训练后突然尿床或能力退化
- 离家出走
- 与年龄不相符的性行为
- 自信心突然改变
- 学校表现或成绩显著变差
- 极端消极或富于攻击性
- 极度亲热或社交恐惧
- 胃口大增、偷食物

## Mental Models
- **"孩子会把大人的事算在自己头上"**：3～5岁的自我中心归因是认知阶段的必然，所以离婚、家人生病时必须明确说"这不是你的错"。
- **"沉默不等于保护"**：对离婚保密会强化他感到的紧张；对虐待隐瞒会让他无法获得帮助。
- **"开放双向的交流是最好的预防"**：让孩子确信"告诉你不会有麻烦，告诉我是为了保护你"。
- **"预防施虐靠支持父母，不靠指责父母"**：家庭内虐待多源于孤独、压力与沮丧；教会父母处理愤怒、并在危机时有人陪伴，才是有效预防。
- **"看护机构必须可随时探访"**：不需预约即可探视，是防机构内虐待最有效的制度设计。

## Anti-patterns
- **对孩子说"他被危险包围"**：会制造焦虑；应说"你是坚强的、有能力的，只要你告诉我，我就能保护你"。
- **把"被收养"当秘密**：孩子迟早知道，隐瞒会破坏信任。
- **离婚期间让孩子当传话筒/裁判**。
- **反复分分合合**：比确定性的离婚对孩子伤害更大。
- **要求孩子"站队"**：会摧毁自我认同。
- **对孩子的"退行"发脾气**：那是压力信号，不是故意倒退。

## Worked Example
一个4岁孩子在父母离婚后的三个月：

| 表现 | 判读 | 应对 |
|---|---|---|
| 突然尿床、要奶瓶 | 3～5岁退行（常见） | 不斥责、不强化；平静处理，恢复日常作息 |
| 说"都是我不乖，爸爸才走" | 3～5岁的自我中心归因 | 明确、反复地说："爸爸妈妈分开是我们大人的事，不是你的错。" |
| 父母交接时哭闹打人 | 分离焦虑 + 忠诚冲突 | 交接简短、情绪稳定；不让他传递消息；不在他面前争执 |
| 节日情绪崩溃 | 特殊日子的失落高峰 | 提前预告安排，允许他怀念，保留与双方各自的固定仪式 |

## Key Takeaways
1. 3～5岁孩子会把离婚归因于自己，必须明确告知"不是你的错"。
2. 离婚期间最伤孩子的不是分开，而是反复分分合合与让孩子卷入冲突。
3. 虐待识别看"解释不匹配"：与描述不符、与运动能力不符的损伤。
4. 4岁以下躯干/耳/颈部淤青、不会翻身婴儿的任何损伤、性传播疾病 → 高度警惕。
5. 预防虐待的关键是支持父母处理压力与愤怒；防机构虐待的关键是"可随时探访"。

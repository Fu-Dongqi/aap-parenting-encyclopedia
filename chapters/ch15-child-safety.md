# 第15章 确保孩子的安全

## Core Idea
儿童伤害不是"意外"，而是**可预测、可预防**的。所有伤害都由三个变量共同决定：**孩子（年龄与性格）、致害物、环境**。孩子和性格你改不了，致害物和环境你全能改——所以安全工作的着力点永远在环境，而不在"更小心一点"。

## Frameworks Introduced
- **伤害三因素模型（Child–Hazard–Environment）**：
  - 随年龄不断自问：他能爬多远、爬多快、够多高？什么吸引他？他昨天不会、今天会、明天还将学会什么？
  - 关键洞察：**大多数伤害不发生在父母警觉、状态良好时，而发生在父母压力大、分心时**（电话铃、敲门、有人生病、搬家、度假、换保姆、父母关系紧张、饭前1小时饥饿疲劳、母亲孕期）。
  - 结论：安全环境的作用是"当你必然分心的那几分钟兜底"。
- **"规矩要重复十几次"原则**：2～4岁孩子处于"以自我为中心的奇幻思维"阶段（认为愿望能控制结果，如划火柴以为能控制火势）。他记不住警告、想不到后果、也控制不住好奇。
  - 做法：定少量硬规矩 + 每次违反都重复 + 说明原因（"不要跑到马路上，因为你会被汽车撞到"）+ **仍不指望他遵守，保持严密看护**。
- **汽车安全座椅"阶段递进"体系**（本书记得最细的一套）：
  1. 婴儿与幼儿：**后向式**，直到超过厂商设定的身高/体重上限（多数可转换座椅允许2岁后仍后向）；
  2. 超过后向上限的幼儿与学龄前：**前向式 + 五点式安全带**，装后排；
  3. 超过前向上限的学龄儿童：**增高型座椅（用车载安全带固定）**，直到身高约145厘米、年龄8～12岁；
  4. 之后可直接用车载安全带：腰部贴大腿、肩带横过胸中部、能靠着椅背且膝在座边弯曲；
  5. **13岁以下一律坐后排**。
- **水域"接触式看护"**：孩子在水里时，成人必须在**一臂之内**，且不看手机、不做别的事。即使他会游泳、即使水很浅。

## Key Concepts
- **意外伤害是1岁以上儿童伤残与死亡的主要原因**，其中车祸与溺水最多。
- **最致命的车祸多发生在离家8千米内、时速低于40千米时**——"就一小段路"是最危险的借口。
- **安全座椅安装检验**：前后左右摇晃幅度**不超过2.54厘米（1英寸）**；安全带紧到"手指捏不起一段"；后向式肩带在肩部或肩下，前向式在肩部或肩上。
- **绝不留孩子在车内**：炎热天气下10分钟内可致死；可用"钱包/鞋放后座""安全座椅上放毛绒玩具作提醒物"等物理提醒。
- **车辆盲区**：不要让孩子在车库和车道玩耍；倒车摄像头拍不到快速移动的小孩。
- **遇陌生狗**：静止站立、不跑不骑车不踢打、面朝狗缓慢后退、避免对视（对视是挑衅）。

## Mental Models
- **"从孩子的视角俯视一遍房间"**：蹲下来，以他的身高看世界——抽屉拉手、桌布垂边、插座孔、热水壶线，全部重新评估。
- **"看不见的房间最危险"**：长期锁着的餐厅、车库、地下室，恰恰是他最想探索的地方。
- **"安全是给自由的预算"**：禁区越少，你越敢放手；安全投入换的是他的探索权。
- **"分心是必然，不是失职"**：承认自己会分心，才会去做环境改造而不是靠意志力盯人。

## Anti-patterns
- **靠"时刻盯着"代替环境改造**：最负责的父母也无法时时刻刻盯住。
- **让孩子坐在大人腿上乘车**：急刹或碰撞时成人根本抱不住，且成人身体会挤压孩子。
- **把后向式座椅装在前排**：气囊爆开会直接挤压座椅，低速碰撞也可致死。
- **使用来源不明/超期/经历碰撞的二手安全座椅**：多数厂商建议最多用6年；无标签、无说明书、有裂缝一律不用。
- **孩子抗议就不系安全带**：明确告知"每个人系好我才开车"，并真的执行。
- **用学步车、洗澡椅、游泳圈替代看护**：AAP 明确反对。
- **把漂白剂/洗涤剂装进饮料瓶**：会吸引孩子品尝。
- **把不用的冰箱/冰柜留在车库且不卸门**：孩子钻入会被困。

## Worked Example
一位爸爸的"分心兜底"改造：他知道自己会在接电话时短暂失守，于是按场景布置：

| 高风险场景 | 改造动作 |
|---|---|
| 客厅（他每天独自玩15分钟） | 插座保护盖、茶几包角、窗帘换无绳款、地面小物件每日巡检 |
| 厨房（晚饭前1小时，最易受伤时段） | 高脚椅扣安全带放视线内；锅柄转向炉后；清洁剂与洗碗凝珠锁入高处柜；备灭火器 |
| 卫生间 | 门上装高位门闩；马桶盖加锁；热水器调至≤49℃；浴缸防滑垫+水龙头罩 |
| 楼梯 | 上下两端装防护门，常关（即使他已会倒退下） |
| 车内 | 后向式座椅装后排，摇晃≤2.54厘米；钱包放后座作提醒；车门常锁、手刹拉起 |

## Key Takeaways
1. 伤害可预测：改环境，不改"更小心"。
2. 汽车座椅五级递进：后向 → 前向五点式 → 增高座（到145厘米/8～12岁）→ 车载安全带；13岁以下坐后排。
3. 婴儿床四条硬指标：栏杆＜6厘米、床垫缝隙≤两指、无防撞护垫、撤除时机（会撑起/5个月撤床铃；90厘米换床）。
4. 水边永远"一臂之内"，不看手机；泳池栅栏≥1.2米、栏杆≤10厘米。
5. 热水≤49℃、绝不留孩子在车内、6岁前不用洗衣凝珠——三条最容易忽视的日常致命点。

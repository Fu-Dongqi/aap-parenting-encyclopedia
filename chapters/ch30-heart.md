# 第30章 心脏问题

## Core Idea
心脏章最重要的信息是**"绝大多数发现都是良性的"**：窦性心律失常、早搏、功能性心脏杂音都不需要治疗，也不会限制运动。真正需要警觉的是四类症状——婴儿突然苍白无力、安静时自述心跳很快、晕厥或眼前发黑、以及喂养困难伴皮肤青紫。

## Frameworks Introduced
- **心率随年龄下降原则（判断"快"与"慢"的前提）**：年龄越小，正常心率越高。
  - 安静新生儿：**130～150次/分**；
  - 安静5岁儿童：上述数值已属过高；
  - 健壮青少年安静时：**50～60次/分**。
  - 判读：发热、哭闹、运动、剧烈活动都会加快心率——**必须在安静状态下判断**。
- **"该担心/不该担心"的心律失常分类**：

| 类型 | 是否需要处理 | 说明 |
|---|---|---|
| 窦性心律失常 | 不需要 | 健康儿童也可能出现，有时仅由呼吸引起，属正常生理 |
| 期前收缩（早搏） | 不需要 | 孩子可能描述"心脏漏跳一下/越过一拍"，一般不代表严重心脏病 |
| 真正的心律失常 | 需要，且**可能很严重** | 包括心动过速、心房扑动（极快）、心房颤动（极快且不规律）、心动过缓（过慢）、间断早搏；可致晕厥甚至心力衰竭，但可有效控制 |

- **杂音的"功能性优先"原则**：学龄前与学龄期儿童听到的杂音，**多数是功能性/单纯性杂音**（健康心脏正常泵血产生），不需治疗，多数会消失（多在青春期中期消失），**不必限制体育运动**。医生通常靠听诊即可区分功能性与病理性，多数不需要额外检查。

## Key Concepts
- **心脏杂音的定义**：听诊时"扑/通——扑/通"之间本应安静，若其间出现任何声音即为杂音。
- **需换心脏的杂音线索**：医生听到明显异常杂音时，会看孩子**皮肤是否青紫**、是否有**呼吸困难或喂养困难**；进一步查胸片、心电图、超声心动图。
- **动脉导管未闭（PDA）**：两条大动脉间血流异常；早产儿多见；多数唯一表现是心脏杂音；足月儿出生后导管自行闭合则杂音消失；早产儿可能不闭合 → 肺血流过多、心脏负荷增加、肺动脉压升高。部分可自愈或药物闭合，持续未闭需手术或心导管治疗。
- **高血压**：约**10%**儿童血压高于正常，但仅**3%～4%**为真正高血压；诊断基于与同年龄同性别健康儿童比较，收缩压或舒张压偏高即算。**超重是主要可控因素**。多数无明确病因；少数是肾脏疾病或心脏、神经、内分泌异常的症状。**从3岁起体检应测血压**。
- **心脏病的"红旗症状"**（出现即就医）：婴儿突然脸色苍白、无精打采、身体非常软弱无力；孩子说安静状态下心跳很快；自诉非常不舒服、软弱或无力；眼前发黑或晕厥。

## Reference Tables

**高血压的可能症状（多数无症状，出现以下需警惕）**

- 头痛
- 头晕
- 呼吸急促
- 视物不清
- 疲劳
- 脚踝肿胀

**心律失常的检查路径**

1. 常规体检发现，或家长描述症状；
2. 心电图（记录心脏电活动）；
3. 症状不易捕捉 → **动态心电图监护仪佩戴1～2天**，同时家长记录孩子的活动与症状时间点（如"下午2:15觉得心颤并眩晕"与心电图尖峰对齐即可确诊）；
4. 仅运动时出现 → 固定自行车或跑步机运动试验同时记录心电图；
5. 必要时请小儿心血管内科会诊。

## Mental Models
- **"杂音是声音，不是诊断"**：绝大多数儿童杂音无需治疗，也不限制运动；关键看有无青紫、呼吸困难、喂养困难。
- **"永远在安静状态下数心率"**：哭闹、发热、运动后的心率不能用于判断心律失常。
- **"晕厥是心脏问题里最不该忽视的一条"**：眼前发黑或晕厥必须查心脏。
- **"血压从3岁开始测"**：儿童高血压多数无症状，靠测量发现；超重是唯一可主动改变的因素。
- **"喂养困难 + 出汗 + 青紫"在婴儿身上是心脏信号**，不是"孩子难带"。

## Anti-patterns
- **因为"有杂音"就限制孩子运动**：功能性杂音不需要限制。
- **因杂音轻微度变化而焦虑**：可能只是每次体检时心率不同。
- **把孩子的"心跳漏一拍"当重病**：早搏一般无需治疗。
- **在哭闹或发热时判断"心跳太快"**：需安静状态复测。
- **认为高血压是成人病**：婴儿也可能有，且儿童期即可起病。
- **忽视超重与久坐**：这是儿童高血压最现实的可控因素。

## Worked Example
一个4岁男孩体检"发现心脏杂音"：

| 环节 | 判读与动作 |
|---|---|
| 体检听到杂音（1～5岁体检常见） | 医生更仔细听诊，区分功能性 vs 病理性 |
| 孩子无青紫、无呼吸困难、无喂养困难、生长正常 | 支持**功能性/单纯性杂音** |
| 医生仅凭听诊即可判断 | 通常不需额外检查，不限制运动 |
| 随访 | 青春期中期多自行消失；杂音强弱随心率变化属正常 |
| 若出现青紫/呼吸困难的异常杂音 | 查胸片、心电图、超声心动图，必要时请小儿心血管内科 |

## Key Takeaways
1. 心率判断必须先安静：新生儿130～150次/分正常，青少年50～60次/分正常。
2. 窦性心律失常与早搏无需治疗；真正的心律失常罕见但可致晕厥、心衰。
3. 儿童杂音多为功能性：不治疗、不限制运动，青春期中期多消失。
4. 心脏红旗四症状：婴儿突然苍白无力、安静时心跳快、晕厥/眼前发黑、明显不适与软弱。
5. 3岁起测血压；10%儿童偏高、3%～4%为真高血压；超重是最可控因素。

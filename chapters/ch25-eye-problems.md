# 第25章 眼部问题

## Core Idea
视觉系统的可塑期在**10岁左右关闭**——此后很多早期眼病将无法逆转。所以儿童眼科的铁律是：**早筛查、早诊断**。你不需要判断孩子有没有病，只需要按时间表去查。

## Frameworks Introduced
- **视力筛查时间表（AAP推荐）**：
  - 出生后出院前：查眼部感染、先天缺陷、白内障、先天性青光眼；所有早产儿或多病新生儿需小儿眼科检查。
  - 6个月：查双眼运动一致性及所有可能眼病；6个月后可用**摄影筛查法**早发现弱视及其危险因素。
  - 3～5岁：**每年**由儿科医生查视力 + 查可能影响学习的发育缺陷。
  - 6岁及以上：**隔年**一次，测视力并评估其他眼部功能。
- **视力达标线（视敏度）**：3岁双眼应达 20/50（4.6）；4岁 20/40（4.7）；6岁起 20/30（4.8）或更好。不达标 → 转小儿眼科。
- **弱视的"遮盖疗法"逻辑**：不是治"坏眼"，而是**逼它工作**——遮住好眼，强制使用弱视眼；或用好眼滴眼液使其视物模糊，达到同样目的。疗程可能几周到几年，直到弱视眼潜能被激发并稳定。**超过7岁（部分孩子10岁）未治，视力可能永久丧失**。

## Key Concepts
- **早产儿视网膜病变（ROP）**：严重影响视力；出生体重**<1.5千克**风险更高；长期氧疗者尤需筛查；早期发现可成功治愈。早产儿还更易有散光、近视、斜视，需整个儿童期定期筛查。
- **新生儿视觉**：出生头几周只能看光线、形状与运动；最佳可视距离**20.3～30.4厘米**（约喂奶时母婴眼距）。
- **双眼协调时间线**：2个月（部分到3个月）眼球"游离"减少 → 3个月能盯人脸并跟随 → 4个月能发现近物并伸手抓 → 6个月能视觉识别物体。
- **白内障**：瞳孔中央呈白色是首要症状；完全遮挡光线的先天性白内障应在**出生后第1个月**手术，之后配隐形或矫正眼镜，约2岁考虑植入人工晶状体，并用眼罩训练至约10岁。
- **结膜炎（红眼病）**：白眼球与下眼睑内侧发红，伴流泪与分泌物；感染性病程7～10天；病毒性用抗生素无效；传染性很强。
- **眼部损伤预防**：90%可预防，约一半发生在家中。

## Reference Tables

**必须找医生的眼部症状（家长可观察）**

| 类别 | 症状 |
|---|---|
| 瞳孔 | 一侧或双侧瞳孔呈白色（白瞳病）；双侧瞳孔不等大 |
| 眼睑/眼表 | 眼或眼睑持续**超过24小时**发红、肿胀、结痂或有分泌物；一侧或双侧眼睑下垂；角膜起雾；眼睑经常"跳" |
| 泪/光 | 不断流泪；对光敏感（尤其敏感性发生变化时） |
| 眼位/运动 | 眼睛歪斜或双眼不能协调运动；头一直保持异常姿势 |
| 行为 | 经常眯眼；经常揉眼睛；不把物体拿近就看不清 |
| 主诉 | 看东西有重影；频繁头痛；近距离用眼后眼痛或轻微头痛；视物模糊；眼痒或烧灼感；色觉障碍 |
| 外伤 | 眼部受损（见下） |

**眼部外伤的现场处理**

| 情形 | 动作 |
|---|---|
| 灰尘/细小颗粒 | 先靠眼泪冲出；冲不出或1小时后仍疼 → 就医 |
| 眼眶发黑 | 毛巾包冰袋冷敷10～20分钟，然后就医（排除骨损伤） |
| 有毒物质入眼 | 用清水充分冲洗（确保水进入眼内），然后**立即急诊** |
| 眼睑切割伤 | 小伤口可自愈；深伤口需急诊缝合；**若在睑缘、靠近睫毛或泪小管开口 → 立即就医** |
| 大异物 | 冲不出 → 就医取出；可能划伤角膜，规范治疗可较快愈合 |

## Mental Models
- **"筛查不是确诊，是筛出风险"**：摄影筛查能在孩子还不会指认视力表时发现弱视危险因素。
- **"斜视/歪头看东西是信号，不是习惯"**：持续歪头、眯眼、揉眼都指向屈光或眼位问题。
- **"不要共用眼药水"**：开封过或他人用过的滴眼液可能造成严重损害。
- **"结膜炎要隔离到不传染"**：通常为分泌物或发红完全消退后24小时，具体由医生判断。

## Anti-patterns
- **以为"孩子小测不准，等上学再查"**：3岁起就应每年查，10岁后不可逆。
- **把白瞳当"反光"忽略**：白瞳病是视网膜母细胞瘤、白内障等的重要信号。
- **用成人或过期眼药水滴孩子眼睛**。
- **孩子患结膜炎仍送托幼机构**：传染性极强。
- **早产儿不查眼底**：ROP 可致盲，但早发现可治。

## Key Takeaways
1. 筛查节奏：出生 → 6个月 → 3～5岁每年 → 6岁后隔年。
2. 视力达标线：3岁20/50、4岁20/40、6岁20/30。
3. 弱视患病率约2%，靠遮盖/模糊好眼强迫使用弱视眼；7～10岁后治疗窗口关闭。
4. 白瞳、持续24小时以上的眼红肿胀、双眼不协调、持续歪头 → 立即就医。
5. 有毒物入眼：清水充分冲洗后立刻急诊，不等待观察。

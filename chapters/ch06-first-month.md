# 第6章 第1个月

## Core Idea
第1个月有两个数字最要紧：**体重（7天内降幅≤10%、2周回到出生体重、满月约4.5千克）**和**哭闹（6周达峰、每天约3小时）**。前者验证喂养是否有效，后者验证神经系统是否在正常成熟。

## Frameworks Introduced
- **反射时间表（判断神经系统成熟度）**：把"会不会"换成"该消失的有没有消失"。
  - 觅食反射、吮吸反射、抓握反射（握持）、踏步反射：踏步约2个月消失、近1岁以自主学步重现。
  - 惊跳反射（莫罗反射）：满月前最常见，约2个月消失。
  - 强直性颈部反射（"击剑"姿势）：5～7个月消失。
  - **判据**：所有反射左右两侧表现应一致；一侧明显不同或更弱 → 找儿科医生。
- **哭闹曲线（正常烦躁 vs 肠痉挛）**：
  - 正常烦躁：2周起，傍晚6点至午夜最重，6周左右达峰（每天约3小时），3～4个月降到1～2小时。
  - 肠痉挛：约1/5婴儿，2～4周最常见，尖叫、蹬腿、放屁、怎么哄都不停，3～4个月消失（个别到6个月）。
  - 处置顺序：先排除疾病 → 母亲忌口（乳制品/大豆/鸡蛋/洋葱/卷心菜，一次只停一种，观察2周）→ 背带背走动、白噪声、安抚奶嘴、趴膝按摩背部、襁褓。
- **大脑早期发育六项需求**：被爱与被重视、安全感、对环境的信心、引导、均衡的自由与约束、丰富环境（语言/游戏/探索/书/音乐/合适玩具）。

## Key Concepts
- **生长爆发期**：第7～10天、第3～6周；体重平均每天增20～30克。
- **头围**：出生约35厘米 → 满月约38厘米；前4个月是颅骨生长最快阶段（头围反映大脑发育）。
- **婴儿痤疮（现称"新生儿脓疱病"）**：第3～5周出现，皮肤对细菌的正常反应，非母体激素。
- **枕秃**：仰卧摩擦所致，无害，几个月后长出新发。
- **体温调节未成熟**：新生儿比身边大人多穿一层；不要包得密不透风。
- **摇晃婴儿综合征**：剧烈摇晃致失明/眼损伤、脑损伤、脊柱损伤、发育受损；症状包括焦躁、昏睡、颤抖、呕吐、抽风、呼吸困难、昏迷。

## Mental Models
- **"哭是唯一可用的语言"**：2周起哭闹增多不是护理失败，是清醒时间变长 + 神经系统尚未自控。回应越快，总哭时长越短。
- **把"清醒时间"当发育指标**：第1个月清醒时间逐日变长、会听、会盯人看、会扭动回应——这比"会不会抬头"更能说明状态。
- **触觉是最早的教育**：肌肤接触、抱着说话、面对面交流，是这一阶段唯一有效的"早教"。
- **先照顾自己，才能照顾婴儿**：情绪失控时把孩子放回婴儿床、离开房间几分钟、打电话求助——这是标准操作，不是失职。

## Anti-patterns
- **担心"抱多了会宠坏"**：这一阶段不存在宠坏，不回应才是风险。
- **用"哭就让他哭"训练睡眠**：第1个月不适用，会损害信任基础。
- **把肠痉挛寄托于市售滴剂**：研究证明无效；有效的是减少刺激、调整喂养节奏、安抚技术。
- **将洗衣机/烘干机当作"白噪声床"**：绝不可把孩子放在上面。
- **忽视反射不对称**：单侧异常是神经系统问题的早期信号。

## Worked Example
一位妈妈在第5周的记录与判定：

| 观察 | 判读 | 动作 |
|---|---|---|
| 每天18:30～21:30 定时尖叫、蹬腿、放屁 | 典型肠痉挛时段（6周达峰） | 不换奶粉、不加滴剂；改为少量多次、喂后充分拍嗝、背带背着走动 |
| 体重比出生时轻7%，第5天开始回升 | 在正常轨道内（≤10%，第5天回升） | 继续按需8～12次/24小时，2周复测 |
| 俯卧时头能左右转，但竖抱时头后仰 | 月龄正常表现（3个月前不能自己竖头） | 竖抱必扶头；每天清醒时多次俯卧练习 |
| 脸上出现小粉刺（第4周） | 新生儿脓疱病 | 每天用温和婴儿皂轻洗一次脸，保持干爽，不挤压 |
| 脐带残端第18天脱落、有少量血性渗出 | 正常（10天～3周脱落） | 保持清洁干燥；若3周仍未愈合再就医 |

## Key Takeaways
1. 体重三节点：7天内降≤10%、第5天起回升、2周回出生体重；满月约4.5千克。
2. 反射看"对称"与"按时消失"，一侧异常立刻就医。
3. 哭闹在6周达峰、每天约3小时是正常的；超过且无法安抚、伴随尖叫蹬腿才是肠痉挛。
4. 头围是大脑发育的窗口：出生35厘米 → 满月38厘米。
5. 任何情况下都不摇晃婴儿；情绪到极限就把孩子放回床上、离开房间求助。

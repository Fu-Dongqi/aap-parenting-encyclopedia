# 第10章 1岁

## Core Idea
1岁是"第一青春期"的开端：他能自己走了，于是开始系统地试探"我的控制力有多大"。这一年的关键词是**独立与依赖的来回摇摆**——他会一会儿挣脱你、一会儿扑回你怀里，两种都是正常的。

## Frameworks Introduced
- **控制力试探模型**：尖叫、拒绝吃饭、跑回禁区不是捣乱，而是在做实验——"我做了X，世界会怎样"。你的稳定回应就是实验的对照组。
  - 应对：给有限的选项（"你想先穿鞋还是先戴帽"），比给无限的自由更能减少对抗。
- **安全判断的"因果缺口"原则**：
  - 他知道"门会开合"，但不知道"手会被夹"；
  - 他知道"车会往下滑"，但想不到"放在马路中间会怎样"；
  - 他甚至无法把"疼"和"导致疼的那串动作"连起来，且下次多半不记得。
  - 结论：**常识建立之前，安全必须靠环境而非靠说教**。
- **依恋—分离的"心理影像"法**：离开前把要去的地方演示给他看，让他脑中形成"你在哪里"的画面，能显著降低分离焦虑（与物体恒存同一机制）。

## Key Concepts
- **生长放缓**：出生第2年只增重1.4～2.3千克；此后到青春期稳步增长。
- **参照值**：15个月女孩约10.5千克/77厘米，男孩约11千克/78厘米；2岁女孩约12.2千克/86厘米，男孩约12.6千克/87.5厘米。
- **头围**：1岁这年只增约2.5厘米；2岁时达成人头围的90%。
- **走路警戒线**：18个月仍不会走路 → 就医。
- **拇食指捏取**：12个月仍吃力，18个月已熟练。
- **"我的"**：占有欲爆发是自我意识发展的标志，出现在词汇量增长之后。
- **自慰/触摸生殖器**：正常好奇心，不是性体验；强烈负面反应会让他以为身体这部分"有问题"。

## Mental Models
- **"平行游戏是正常的"**：1岁的"一起玩"其实是各玩各的、抢玩具。分享的概念此时毫无意义——多准备几份玩具，随时准备当调解员。
- **给玩具"难度分级"**：太简单会无聊走开，太难会抗拒。他自己最清楚能力边界，你只需提供丰富选项让他自己挑。
- **模仿即课程**：他会用梳子梳头、对着电话咿呀、转动方向盘——你做什么他就学什么。此时"身教"就是唯一有效的教育。
- **说话用"标准名"**：说"脚趾"而不是"小猪脚"；放慢语速、吐字清楚、用短句。

## Anti-patterns
- **嘲笑发音错误或催他快说**：会打击表达意愿；正确做法是复述正确发音（"对了，这是球！"）。
- **强迫幼儿改用某只手**：用手偏好可能几年后才明确，甚至终身双手并用，不必干预。
- **把"打人"当探索忽略**：他确实不知道会伤人，但必须立刻拉开并明确说"不能打人"。
- **在公共场所与他对抗**：直接带离现场，平静不解释，等他平静再回来。
- **把"分享"当道德要求**：这个年龄不理解分享，只会感到被剥夺。

## Worked Example
15个月宝宝的一天里三个冲突的处理：

| 场景 | 错误做法 | 按本章框架的做法 |
|---|---|---|
| 拿走他手里的危险物，他尖叫 | 训斥"不许叫" | 平静说出他的感受（"你很生气，因为我把东西拿走了"），同时提供替代物 |
| 他反复跑向旋转门 | 反复口头警告 | 抱离 + 物理隔离（门栏/围挡）；不指望他记住 |
| 你出门上班他大哭 | 偷偷溜走 | 出门前带他看"妈妈去这里"，说明"妈妈会回来"，然后干脆告别 |

## Key Takeaways
1. 18个月不会走路要就医；学步后约6个月步态才趋成熟。
2. 这一年生长明显放缓（＋1.4～2.3千克），别拿增长速度跟婴儿期比。
3. 安全靠环境不靠说教：他缺乏因果推演能力，也记不住教训。
4. 说标准名称、放慢语速、复述而非纠正，是语言发展的三个动作。
5. 独立与依赖来回摇摆（"第一青春期"）是正常心理任务，不是退步。

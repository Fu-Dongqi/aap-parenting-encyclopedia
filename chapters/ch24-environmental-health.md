# 第24章 环境与健康

## Core Idea
环境毒素无法完全避免，但可以显著减量。这一章的判断逻辑统一：**孩子的体重小、呼吸快、行为习惯（手-口探索）特殊，所以同样的暴露剂量对孩子更危险**。因此所有"成人可接受"的标准，在孩子身上要再降一档。

## Frameworks Introduced
- **"儿童剂量放大"原理**：儿童呼吸频率高于成人，每千克体重吸入的空气污染物与摄入的一氧化碳更多；幼儿又常把手和物品放进嘴里。所以同一环境对成人无害，对孩子可能有害。
- **饮水三步（铅与污染物）**：
  1. 每天早上首次饮水/烹饪前，**打开水龙头放水约2分钟**冲洗管道（降低铅等污染物）；
  2. 1岁以下用**井水**冲配方奶前，必须检测**硝酸盐**（>10毫克/升不可饮用与烹饪）；
  3. 井水每3个月或至少每年检测一次硝酸盐；结果安全后改为每年一次。
- **低汞鱼"白名单+限量"**：优选罐装淡金枪鱼、鲑鱼、虾、鳕鱼、鲶鱼、蛤蜊、比目鱼、螃蟹、扇贝、明太鱼；**儿童每周总量少于340克**；避免国王鲭、剑鱼、鲨鱼、方头鱼。

## Key Concepts
- **地面臭氧**：无色气体，氮氧化物与挥发性有机物在阳光下反应生成，是雾霾主要成分；夏季晴朗白天最高、**中午到下午达峰**，冬季也可能偏高，可随风影响农村。哮喘儿童最敏感。
- **石棉**：1940s～1970s 广泛用于防火、绝缘、隔音；**不腐烂破碎就无害**；纤维吸入可致肺/咽喉/消化道慢性病，含潜伏**50年**才发病的间皮瘤。
- **一氧化碳**：无色无味，来自汽油/天然气/木炭/柴油/煤油/丙烷设备与汽车；破坏血液携氧能力；症状为头痛、恶心、气短、疲惫、神志不清、眩晕；长期暴露致性格改变、记忆丧失、肺与脑损伤甚至死亡。
- **双酚A（BPA）与邻苯二甲酸酯**：BPA 使塑料变硬、防菌、防罐头变质；邻苯二甲酸酯使塑料柔软可变形；动物实验显示影响内分泌，BPA 起弱雌激素作用。
- **氟化物**：自来水加氟显著降低龋齿率，是安全有效的方式；**自来水优于瓶装水**（瓶装水多未加氟，且部分品牌其实就是自来水）；无法通过自来水获得氟化物的儿童1岁前看牙医尤其重要。
- **铅来源**：1978年前含铅涂料（墙壁、门柱、窗框）、含铅水管、彩绘玻璃/颜料/焊料/钓坠、老百叶窗、建筑陶瓷器皿（装酸性或热食会析出铅）、有焊缝罐头、含铅糖果香料化妆品、含木炭牙膏、出牙项链。

## Reference Tables

**环境风险 → 防护动作**

| 风险源 | 关键事实 | 动作 |
|---|---|---|
| 户外空气污染/臭氧 | 夏季午后达峰；儿童吸入量按体重更高 | 看空气质量预报；污染日减少户外活动，哮喘儿留在室内 |
| 石棉 | 完好时无害，破碎才释放纤维 | 怀疑即请专业检测；不让孩子在破损材料附近玩；翻修前由认证承包商清除 |
| 一氧化碳 | 无色无味，密闭空间迅速聚集 | 装探测器（卧室、炉灶附近）并定期检查；车库不怠速；发电机/炭火烤炉只在户外；燃气设备每年专业检查 |
| 饮用水 | 铅标准非基于健康标准；井水可能硝酸盐超标 | 晨起放水2分钟；井水检测硝酸盐（>10 mg/L 不可饮用）；1岁以下不用未检测井水冲奶 |
| 鱼 | 甲基汞损害发育中的神经系统；PCBs与二噁英亦有风险 | 只用低汞白名单，每周<340克；避免国王鲭/剑鱼/鲨鱼/方头鱼 |
| 铅 | 1978年前涂料；父母职业带回家 | 老房检测；工作后淋浴换衣、工作服单独洗；不用建筑陶瓷装酸性/热食；不买出牙项链 |
| 塑料容器 | 加热促使BPA释放 | 避开回收标志**7号**与**PC**字样；不微波加热、不用洗碗机清洗塑料奶瓶；可选玻璃瓶（注意碎裂） |

## Mental Models
- **"破损才危险"**：石棉、旧漆、老百叶窗在完好状态下风险低；一旦起皮、破碎、翻修，风险立刻上升——所以"刷一层新漆盖住"是安全的错觉。
- **"通风与室外"是通用解**：装修通风、新家具先通风、燃气与发电机放室外、车库不怠速。
- **"不要用'纯天然/替代品'自我安慰"**：BPA 的替代化学物同样缺乏安全性数据；瓶装水不等于更安全。
- **"汞是神经毒，作用于发育中的大脑"**：所以孕妇与儿童的限制最严，且没有"安全累积量"可言。

## Anti-patterns
- **污染日仍让孩子长时间户外活动**（尤其哮喘儿）。
- **在室内或密闭空间用炭火烤炉、便携野营炉、发电机**：急性一氧化碳中毒。
- **汽车在密闭车库保持启动**：同上。
- **用未检测井水冲调婴儿配方奶**：硝酸盐→高铁血红蛋白血症（可致命）。
- **用建筑陶瓷器皿装橙汁或热汤**：酸与热析出铅。
- **给婴儿戴"出牙项链"**：含铅且可致呼吸道阻塞与勒颈；改用冷冻香蕉、牙胶、凉湿干净棉布。
- **微波加热塑料奶瓶或用洗碗机清洗**：促 BPA 释放。
- **只依赖瓶装水**：多数未加氟，龋齿风险升高。

## Worked Example
一个有哮喘孩子的家庭，把本章转成一张可执行清单：

| 场景 | 动作 |
|---|---|
| 夏季午后出门前 | 查空气质量指数；臭氧高 → 改室内活动 |
| 每日清晨 | 厨房水龙头放水2分钟后再接水做饭/冲奶 |
| 每月1日 | 检查烟雾与一氧化碳探测器（每层至少1个，卧室与炉灶附近） |
| 每周菜单 | 鱼只用低汞白名单，总量控制在340克内，分2次 |
| 车库 | 车辆不怠速；发电机与炭火烤炉只在室外，且远离开着的窗与通风口 |
| 老房翻修 | 先测含铅涂料与石棉；不自行打磨起皮墙面；由认证承包商处理 |
| 厨房存放 | 塑料奶瓶标注"无BPA"；不微波；改用玻璃或标注安全的材质 |

## Key Takeaways
1. 儿童按体重摄入更多空气与污染物，所有成人标准对孩子都要再降一档。
2. 一氧化碳无色无味：探测器 + 设备放室外 + 车库不怠速，是三条硬规则。
3. 井水必须测硝酸盐（>10 mg/L 禁用），1岁以下尤其；晨起放水2分钟降铅。
4. 低汞鱼每周<340克，避开国王鲭、剑鱼、鲨鱼、方头鱼。
5. 避开回收标志7号与"PC"塑料、不微波加热；自来水（含氟）优于瓶装水。

# 第4章 婴儿的喂养

## Core Idea
母乳是1岁以下婴儿的最佳营养来源，AAP 的默认处方是：**出生1小时内开奶、按需喂养8～12次/24小时、纯母乳6个月、加辅食后继续母乳到至少1岁**。配方奶是"仅次于母乳的可接受选择"，而不是等价选择。

## Frameworks Introduced
- **含乳四要点（决定喂养成败的技术核心）**：不只看"吃多久"，看这四条。
  - 嘴张大、嘴唇外翻成鱼嘴状；
  - 下腭大大张开，含住**大部分乳晕**（不只是乳头），乳头在口腔深处；
  - 有节奏有力地吮吸，中间有停顿；
  - 能听到规律吞咽声，母亲乳头在头几次吮吸后转为舒适而非疼痛。
- **"我的孩子吃饱了吗"三层判据**：
  - 过程层：吞咽声、吮吸节奏、吃完自己松开乳头或进入非营养性吮吸后昏睡；
  - 身体层：射乳反射迹象（宫缩痛、喷射感、另侧漏奶、喂前饱胀喂后变软）；
  - 结果层：体重按生长曲线增长（终极判据，见附录曲线）。
- **按需喂养（而非按时）**：以饥饿信号启动喂奶，而不是看钟。
  - 早期信号：睡中转醒且清醒、手往嘴里送、吮吸动作、"呜呜/嘤嘤"声、身体活跃、鼻子蹭胸。
  - 关键判断：**啼哭是饿过头的迹象**，应在哭之前喂。

## Key Concepts
- **初乳 → 过渡乳 → 成熟乳**：产后2～5天初乳（淡黄、富蛋白与抗体）；随后过渡乳（乳房发胀）；1周后转乳白，10～14天稳定。
- **前奶/后奶**：前段富碳水，后段富脂肪与热量；因此"一侧吃空"优于"两侧各吃一点"。
- **射乳反射**：催产素驱动的排乳反射，由吮吸或听到哭声触发；同时引起产后宫缩痛（说明宝宝确实吃到了）。
- **催乳素**：排乳后刺激更多乳汁分泌。
- **涨奶**：乳汁与体液过度充盈；处理顺序为频繁喂 → 热敷促流动 → 必要时先挤出少量让宝宝好含乳 → 喂后冷敷 → 布洛芬（遵医嘱）。
- **乳头内陷**：正常生理变异，可用吸奶器先吸出或暂用乳头保护罩。

## Mental Models
- **母乳的价值不在"营养表"而在"活成分"**：酶、抗体、促生长因子、随月龄自动调节的配比——配方奶只能"近似"，这是结构性差距，不是参数差距。
- **喂养是双向技能，不是母亲单方面的任务**：婴儿要学含乳，母亲要学姿势（摇篮式、橄榄球式/侧抱，剖宫产首选后者避开腹部）。3～4周母乳稳定后，父亲可用奶瓶喂挤出的母乳。
- **"疼"是技术问题，不是忍耐问题**：母乳喂养不应引起长时间乳头/乳房疼痛。持续疼痛 = 含乳方式有误，找哺乳顾问，而不是硬扛或直接断奶。
- **早期用奶瓶/安抚奶嘴有代价**：头几周尽量不用，等母乳喂养稳定后再引入，避免"乳头混淆"。

## Anti-patterns
- **只叼乳头不含乳晕**：吸不到奶且必然疼痛、皲裂、流血。
- **按钟表喂奶、等哭了再喂**：哭泣已是晚期信号，会削弱吮吸效率与泌乳刺激。
- **"锻炼乳头"**（拉抻、揉搓、摩擦）：会损伤乳晕润滑腺体，越练越痛。
- **因涨奶而减少喂奶**：越不喂越胀；正确是增加频率（8～12次/天）并排空。
- **哺乳期自行服药或信"纯天然"**：成分可进入乳汁，须先问医生。

## Worked Example
一位剖宫产妈妈的第一个月喂养调试过程：

| 问题 | 判断 | 动作 |
|---|---|---|
| 喂奶时乳头刺痛、有皲裂 | 含乳只含乳头 | 改橄榄球式抱法（避开腹部伤口），拇指在上四指在下托乳，宝宝嘴张大时"带向乳房"，手指离乳晕≥5厘米 |
| 感觉不到射乳、担心没奶 | 看结果信号而非感觉 | 观察吞咽声、吃完是否自行松开、喂后乳房是否变软；喂前湿热敷、背部支撑、深呼吸/轻音乐 |
| 第5天乳房硬如石、宝宝含不住 | 涨奶 | 喂前热敷+手挤少量软化→ 再含乳 → 喂后冷敷 → 布洛芬（遵医嘱） |
| 家人想帮忙 | 3～4周稳定后引入奶瓶 | 父亲用奶瓶喂挤出母乳，承担拍嗝、换尿布、洗澡、散步 |
| 满月体重增长偏慢 | 回到三层判据+生长曲线 | 记录每次哺乳时间，确保24小时≥8次；必要时请哺乳顾问上门 |

## Key Takeaways
1. 纯母乳6个月、之后加辅食并继续哺乳到至少1岁；出生1小时内开奶。
2. 每24小时8～12次按需喂养，用饥饿的早期信号启动，不要等到哭。
3. 含乳看"含住大部分乳晕+有吞咽声+乳头不痛"，三项缺一即为技术错误。
4. 母乳婴儿必须补维生素D 400 IU/天（1岁后600 IU）。
5. 一侧吃空再换边，前奶碳水、后奶脂肪，换边太勤等于只吃了"前菜"。

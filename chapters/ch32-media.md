# 第32章　媒体问题

> 原文位置：L11878–11941

## Core Idea

媒体（屏幕）不是"好"或"坏"的二元问题，而是**剂量 + 内容 + 是否有人陪**三个变量共同决定影响方向。AAP 给出的不是模糊建议，而是**按年龄分层的硬性时间上限**。这一章的价值在于它把"能不能看屏幕"变成了"几岁、看多少、看什么、谁陪"四个可判定的问题。

## Frameworks Introduced

### 1. AAP 分龄屏幕规则（硬阈值）
| 年龄 | 规则 |
|---|---|
| < 18 个月 | **避免**使用屏幕，**唯一例外**：视频聊天（因为它有真人互动） |
| 18–24 个月 | 只看**高质量内容**，且**家长必须陪同**观看、解说 |
| 2–5 岁 | 每天 **≤1 小时**高质量内容，家长共同观看 |
| 6 岁以上 | 需设定一致的时限 + 内容边界（并保证不侵占睡眠、运动、学业） |

### 2. 影响机制四通道
屏幕通过四条路径影响孩子，识别通道才能对症处理：
1. **注意力劫持**：背景电视每分钟吸引约 3 次注视 → 打断正在进行的玩耍
2. **睡眠推迟**：蓝光抑制褪黑素；睡前 ≥60 分钟关屏
3. **肥胖**：主因是**食品广告**，不是"看电视代替了运动"
4. **行为模仿**：暴力内容影响攻击行为

## Key Concepts

- **背景电视（background TV）**：即使没人看，只要开着就在消耗孩子的注意力。每分钟约 3 次注视转移——这是"屏幕即使不看也有害"的量化证据。
- **蓝光与睡眠**：睡前 ≥60 分钟停止使用屏幕。这条比"少看"更具体、更可执行。
- **食品广告 ≠ 运动减少**：这是本章最反直觉的一条。儿童肥胖与屏幕时间的关联，主要中介变量是**看广告后摄入的高热量食品**，而不是活动量下降。
- **视频聊天的例外地位**：唯一被 AAP 明确豁免的 <18 个月屏幕使用，因为它具备真人双向互动属性。
- **共同观看（co-viewing）**：家长陪同不是监督，是**解说**——把内容转成语言互动。

## Mental Models

**"屏幕时间不是时间账，是注意力账。"**
背景电视每分钟 3 次注视，意味着"开着但没在看"仍在扣款。关掉比限时更有效。

**"内容质量 > 时长，但在低龄段时长先卡死。"**
2–5 岁先卡 1 小时/天上限，再谈内容；<18 个月除了视频聊天一律不谈。

**"肥胖的杠杆在广告，不在沙发。"**
如果目标是控制体重，限制含食品广告的内容比强制户外活动更直接命中机制。

## Anti-patterns

- ❌ 把"视频聊天"也算进屏幕时间 → 它是唯一被豁免的例外，因为它有真人互动。
- ❌ 认为"开着电视但孩子在玩玩具，不算看屏幕" → 背景电视每分钟 3 次注视，正在持续打断。
- ❌ 用"减少屏幕时间"来减肥，却不筛内容 → 漏掉了食品广告才是主要中介。
- ❌ 睡前用"看个动画片平静一下" → 蓝光 + 内容刺激双向上推入睡时间，应提前 60 分钟关屏。
- ❌ 18–24 个月让孩子独自看"教育节目" → 必须有家长陪同解说才成立。

## Worked Example

一位妈妈说她 3 岁的孩子每天看 2.5 小时动画，主要诉求是"控制体重，孩子有点胖"。

按本章机制拆解：
1. **先卡时长**：2–5 岁上限 1 小时/天。当前 2.5 小时，超 150%。
2. **再查内容**：书中指出肥胖的主要中介是**食品广告**，不是活动量下降。所以第二步不是"赶出门跑步"，而是看这 2.5 小时里有多少带食品广告的内容——削减这块的收益最直接。
3. **处理背景电视**：家里是否常开着电视？每分钟约 3 次注视，即使孩子在玩也在消耗注意力。先关掉，这一步不花任何成本。
4. **处理睡前**：睡前 60 分钟关屏，因为蓝光影响睡眠；睡眠不足本身也会推高食欲。
5. **最后才是时长替换**：把省下的 1.5 小时换成户外活动——但这是第四步，不是第一步。

书中顺序的逻辑：**先改机制明确的（广告、背景电视、睡前蓝光），再改机制间接的（运动量）。**

## Key Takeaways

1. <18 个月：除视频聊天外避免屏幕。
2. 18–24 个月：高质量内容 + 家长陪同，两者缺一不可。
3. 2–5 岁：≤1 小时/天。
4. 背景电视每分钟约 3 次注视劫持 → 不看也要关。
5. 睡前 ≥60 分钟关屏（蓝光影响睡眠）。
6. 屏幕—肥胖的主要中介是**食品广告**，不是活动量下降。
7. 暴力内容会影响攻击行为，需按内容分级筛选。

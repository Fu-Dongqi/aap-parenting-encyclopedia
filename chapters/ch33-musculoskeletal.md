# 第33章　肌肉、骨骼问题

> 原文位置：L11942–12066

## Core Idea

儿童肌肉骨骼问题的主线不是"关节痛"，而是**跛行（limp）和步态异常**。孩子很少主动诉说关节疼——书中反复强调这一点：JIA 患儿"通常并不抱怨自己很疼，而以僵直和肿胀为最显著的症状"。所以判断路径必须落在**观察走路**，而不是等孩子说痛。

第二主线：**绝大多数腿型和足弓问题会自愈，而所有矫正器具都无效甚至有害。** O 形腿、X 形腿、扁平足、鸽趾，书中给出的处理基本都是"观察 + 红线清单"，明确否定矫正鞋、鞋垫、支架、扭转带。这是本章最反直觉、也最需要顶住家长压力的部分。

## Frameworks Introduced

### 1. 跛行的六因鉴别（已会走路的孩子突然跛行）
按可能性与危险度排序：
1. **幼儿骨折**——胫骨螺旋形骨折
2. **髋关节损伤或炎症（一过性滑膜炎）**
3. **之前未检出的发育性髋关节脱位（DDH）**
4. **骨或关节感染**（脓毒性关节炎 / 骨髓炎）
5. **科勒病**（足舟骨缺血）
6. **幼年特发性关节炎（JIA）**

### 2. JIA 诊断双条件
必须同时满足：
- 体格检查发现关节炎迹象（肿胀 / 活动范围内疼痛 / 活动受限 / 畸形）
- **持续 ≥6 周**，且排除其他病因

**关键补充**：ANA 阳性 → 葡萄膜炎风险高 → 眼科随访频率由 ANA 结果决定；所有 JIA 患儿都应在病程早期看眼科。

### 3. 腿型发育时间轴（判断"正常"还是"病"的标尺）
```
出生～2岁：O 形腿（正常）
2～6岁：逐渐转为 X 形腿（正常）
之后：自行变直
部分孩子到 9～10 岁才完全变直
```
偏离这条曲线才需要警惕。

## Key Concepts

- **脓毒性关节炎 / 骨髓炎**：发热 + 关节红肿 + 拒绝负重 + 患肢活动减弱。**小婴儿可能只表现为烦躁不安、拒绝用一侧肢体**。髋关节深在，红肿不明显，但孩子会把腿屈曲、拒绝任何方向移动。需影像学 + 可能针吸引流 + 静脉抗生素。**这是急症。**
- **莱姆病**：蜱咬部位**环形红斑** → 后续更小的类似皮疹 + 流感样症状 → 关节炎在出疹后数周至数月出现。**AAP 不建议蜱咬后常规预防性用抗生素**（多数蜱咬不传播、抗生素有副作用、耐药风险）；**也不建议刚被咬就抽血查抗体**（抗体需要时间才出现）。
- **一过性髋关节滑膜炎**：儿童**最常见**的关节炎，2–10 岁，常继发于病毒感染，数天到数周完全消失、无后遗症。治疗：休息 + 布洛芬。
- **牵拉肘（保姆肘）**：**4 岁以下**高发，手臂被全力拉长时软组织卡入肘关节。**不肿**，孩子把手臂紧靠身体、肘微屈、手掌朝身体。复位后疼痛立即缓解、几分钟内恢复正常。预防：**从腋下抱，不拽手和手腕，不拎着手臂摆动。**
- **幼儿骨折**：胫骨螺旋形骨折，常发生在绊倒、跳跃、摔倒、坐大人腿上滑滑梯时。孩子通常说不清受伤过程。
- **扁平足**：婴儿几乎都是扁平足；**接近 6 岁**足弓发育完成；**10 个孩子只有 1–2 个**带着扁平足进成年。**矫正鞋垫不能帮助足弓发育，还可能引起其他问题。**
- **扭伤分级**：1 级（过度拉伸，2 周内痊愈）/ 2 级（部分撕裂）/ 3 级（完全撕裂）。幼儿扭伤少，因为**韧带比所连接的骨更强**——所以幼儿受伤更可能是骨折而非扭伤。
- **鸽趾（足内翻）三种来源**：跖骨内收畸形（婴儿期，1 岁前多自愈）/ 胫骨内旋（2 岁）/ 股骨内旋（3–10 岁）。

## Mental Models

**"孩子不说疼，所以看走路。"**
JIA 的典型表现是"不抱怨疼痛但有跛行，且清晨和小睡起床后最明显，活动后减轻"。把观察点放在步态和晨僵，而不是疼痛主诉。

**"腿型是曲线，不是快照。"**
单次看到 O 形腿或 X 形腿没有意义，要看它在时间轴上的位置和方向。2 岁前的 O 形腿是正常的；2 岁后 O 形腿**加重**才是红线。

**"矫正器具在这个领域基本是负资产。"**
O/X 形腿、扁平足、鸽趾，书中逐一否定了支架、矫正鞋、鞋垫、扭转带、夜间支撑鞋。它们不改善问题，还可能妨碍玩耍行走并带来心理压力。**能开的处方是"观察 + 红线清单"，不是器具。**

**"幼儿的韧带比骨强，所以先想骨折。"**
成人扭伤多、幼儿骨折多。这个解剖差异直接改变影像学决策的倾向。

## Anti-patterns

- ❌ 孩子跛行但没喊疼 → 当作"玩累了"观察几天。JIA 恰恰以无痛跛行为特征。
- ❌ 因为怕莱姆病，蜱咬后马上吃抗生素 / 马上抽血 → 书中两条都明确否定了。
- ❌ 给扁平足孩子配矫正鞋垫 → 不能促进足弓发育，还可能引发别的问题。
- ❌ 给 O 形腿 / X 形腿 / 鸽趾上支架、扭转带 → 无证据有效，可能阻碍发育。
- ❌ 拽着孩子的手腕把他拎起来或荡秋千 → 这是牵拉肘的标准成因。
- ❌ 幼儿踝部受伤先默认"扭伤" → 幼儿韧带强于骨，更可能是骨折，需影像学排除。
- ❌ JIA 只看风湿科不看眼科 → 葡萄膜炎不治疗可致失明，ANA 阳性者风险最高。

### 跛行处理时间规则
| 情形 | 处理 |
|---|---|
| 刚开始学走路就跛行 | **尽快检查**（可能是脑瘫等神经病变；拖越久越难纠正） |
| 已会走路、突然跛行 | 可先观察 **24 小时** |
| 次晨仍跛行 / 严重疼痛 / 高热 | 立即就医 |

### 取蜱五步
1. 酒精棉球擦拭蜱虫区域
2. 用镊子/小钳子夹住**尽可能靠近皮肤和蜱虫嘴部**的位置
3. 轻柔但**持续**的力把蜱虫**整个**拔出
4. 确保蜱虫死亡后再丢弃，全程用纸巾/棉布遮挡，避免接触病原体
5. 拔出后用酒精或肥皂彻底清洗咬伤区

## Worked Example

**场景**：3 岁男孩，感冒好转后第 5 天开始不肯走路，家长说"没听他喊疼"。查体：左腿屈曲、拒绝伸直、拒绝任何方向活动髋部，体温 37.8℃。

判断路径：
1. **首先排除急症**。发热 + 拒绝负重 + 拒绝髋部任何方向活动 → 必须排除**脓毒性关节炎 / 骨髓炎**。髋关节位置深，红肿不明显，这是最容易被漏的表现。→ **立即就医，不能在家观察 24 小时。**
2. **若能排除感染**，则最可能是**一过性髋关节滑膜炎**（2–10 岁最常见，继发于病毒感染，数天到数周自愈）。处理是休息 + 布洛芬。
3. **注意"没喊疼"这个信息不要当成轻症证据**。书中明确：JIA 患儿通常不抱怨疼痛，最显著的是僵直和肿胀；且跛行在清晨和小睡后最明显，活动后减轻。如果症状持续 **≥6 周**，就要按 JIA 的诊断路径走。
4. **若走向 JIA**：查体确认关节炎迹象 + 病程 ≥6 周 + 排除其他病因 → 转风湿科；同时**查 ANA 并早期看眼科**（ANA 阳性者葡萄膜炎风险最高，不治疗可致失明）。
5. **家长沟通的落点**：真正需要记住的不是病名，而是"发热 + 不肯用腿 = 当天就医；无热 + 跛行 = 可观察 24 小时，次晨不好就就医"。

## Key Takeaways

1. 儿童关节病的主线索是**跛行**，不是疼痛主诉。
2. **发热 + 拒绝负重 + 拒绝活动关节 = 急症**，当天就医。
3. 跛行观察窗：已会走路者可观察 **24 小时**；学步期跛行**立即查**。
4. JIA 诊断 = 关节炎体征 + **≥6 周** + 排除其他病因；**必须早期看眼科**。
5. 莱姆病：蜱咬后**不**预防性用抗生素、**不**即刻抽血；环形红斑 + 后续小皮疹是特征。
6. 扁平足 6 岁前是常态，10 个里只有 1–2 个持续到成年；矫正鞋垫无效。
7. O/X 形腿、鸽趾一律"观察 + 红线"，矫形器具无证据且有害。
8. 牵拉肘 4 岁以下，**从腋下抱**，不拽手腕。

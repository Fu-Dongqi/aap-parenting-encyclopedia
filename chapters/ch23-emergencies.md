# 第23章 急诊

## Core Idea
急诊章只有两个问题：**"这算不算急症"**（判断），和**"在救护车来之前做什么"**（动作）。判断错了会延误，动作错了会加重——比如催吐、往嘴里塞东西、给烧伤涂油，全都属于"好心办坏事"。

## Frameworks Introduced
- **急症的判定清单（出现任一 → 需紧急医疗救护）**：
  - 行为异常、对刺激反应迟钝；
  - 呼吸困难；
  - 皮肤或嘴唇发青/发紫（深肤色孩子表现为皮肤发灰）；
  - 面积大或程度深的切割伤或烧伤；
  - 流血不止；
  - 有规律地抽搐 + 意识丧失；
  - 昏迷；
  - 头部受伤后出现意识改变、神志不清、严重头痛或呕吐；
  - 牙齿被磕掉/松动，或其他严重嘴面部损伤；
  - 严重的持续性疼痛或疼痛加重。
- **现场四步（真正的急症）**：1）保持镇定 → 2）无反应且无呼吸则开始心肺复苏（若会）→ 3）拨打急救电话 → 4）出血则用干净布持续压迫。
- **抽搐处置三要三不要**：要放在铺地毯/衣物的地板上；要把头转向一侧（保持气道通畅）；要陪到急救人员到。**不要**往嘴里放任何东西；不要试图按住肢体；不要人为催吐/灌盐水/给吐根糖浆。
- **烧烫伤五步**：1）立即凉水冲（足够久，冷却并止痛）；2）凉水浸泡可能燃烧的衣物后轻轻移除（粘住的剪开、不硬撕）；3）无渗出→无菌纱布或清洁干棉布覆盖；4）有渗出→无菌纱布轻覆并**立即就医**；5）**不涂**黄油/油脂/芥末/调味粉，**不放冰块**，**不摩擦**。

## Key Concepts
- **真正的急症定义**：可能威胁生命，或可能造成永久性损伤。
- **常见致伤原因**：机动车相关损伤、撞击（自行车）、被倒下的电视/家具砸伤、高处坠落、中毒、烧伤或吸入烟雾、呼吸道异物、溺水（含非致命性溺水）、严重头部或运动损伤、枪械伤、电击伤。
- **去医院要带**：正在服用的所有药物、疫苗接种记录、怀疑误食的毒物或药物、复杂病史者的旧病历（含手术日期与类型）。
- **汽车安全座椅信息贴纸**：写上孩子姓名、出生日期、父母姓名与电话、特殊医疗需求或严重过敏；贴在急救人员易发现、车外不易看到的位置。
- **狂犬病**：人感染后表现为高热、吞咽困难、惊厥，最终死亡；美国年均人狂犬病死亡仅2～3例（得益于动物管制、疫苗与免疫球蛋白）。野生动物（蝙蝠、臭鼬、浣熊、土狼、狐狸）咬伤风险远高于已免疫的猫狗。
- **"健康动物观察10天"**：若咬人的是健康狗或猫，先观察该动物10天，出现狂犬病症状再启动孩子的治疗。

## Reference Tables

**咬伤：处理与感染征象**

| 阶段 | 动作 |
|---|---|
| 出血 | 持续按压5分钟或至止血 |
| 清洗 | 清水+肥皂轻洗 |
| 就医 | **任何动物咬伤，无论伤口多小，都要就医**（评估破伤风、狂犬病） |
| 特别注意 | 面部/头部/颈部咬伤在儿童中常见且可能严重，必须由医务人员检查 |
| 缝合 | 动物咬伤缝合会增加感染风险，医生可能选择不缝或用抗生素 |
| 感染征象（出现即就医） | 伤口流脓或污水；紧邻伤口肿胀触痛（发红2～3天属正常）；红线从伤口向外延伸；伤口上方淋巴结肿大 |

**需要抗生素的咬伤情形**：中度到重度；穿透骨头/肌腱/关节；脸部；手部与足部；生殖器部位；免疫功能较差或脾切除的孩子。

**烧伤分级与住院指征**

| 分级 | 表现 |
|---|---|
| 一度 | 皮肤发红、轻微肿胀（类似晒伤） |
| 二度 | 疼痛、水疱、较严重肿胀 |
| 三度 | 感觉缺失，皮肤发白或发焦，伤及皮肤深层 |

**必须住院**：三度烧伤；体表面积≥10%；累及脸/手/足/生殖器/关节，或伤处呈环绕状；孩子太小或持续尖叫哭闹、居家处理困难。

**预防呼吸道异物阻塞（关键年龄段与食物）**

| 规则 | 细节 |
|---|---|
| 4岁前不吃需咀嚼的硬而光滑食物 | 花生、生蔬菜；坚果整颗不给，开始吃时一次一颗并观察咀嚼 |
| 圆形硬食物必须切碎 | 火腿肠、葡萄、胡萝卜——**纵切后再切小块，每块边长≤1厘米** |
| 4岁前不吃弹性食物 | 棉花糖、水果软糖 |
| 进食必须坐着且有人看护 | 不边跑边吃、不躺着吃 |
| 高危物品 | 小球、弹珠、气球碎片、玩具小部件、硬币 |

## Mental Models
- **"先分类，再施救"**：是出血、窒息、抽搐、烧伤还是中毒？每一类的第一动作完全不同，慌乱中做错第一动作代价最大。
- **"压迫止血优于一切"**：直接持续按压是最有效的止血手段，别反复松手查看。
- **"烧伤的敌人是热，不是细菌"**：第一件事是降温（凉水冲），不是涂药。
- **"所有动物咬伤都要看医生"**：伤口大小与狂犬病/感染风险无关。
- **"别用手指掏异物"**：会把异物推得更深（见 Ch19）。

## Anti-patterns
- **中毒后催吐、灌盐水、给吐根糖浆**：会进一步损伤（除非医生明确指示）。
- **抽搐时往嘴里塞东西**：可能被咬伤或造成窒息。
- **烧伤涂黄油/酱油/牙膏**：加重损伤、增加感染。
- **烧伤放冰块**：延缓愈合。
- **摩擦烧伤部位**：使水疱增多。
- **不就医的"小"动物咬伤**：遗漏破伤风与狂犬病评估。
- **在室内燃放烟花爆竹（含儿童烟花）**：AAP 明确不建议。

## Worked Example
一个2岁孩子打翻热水杯后的5分钟：

| 时间 | 动作 |
|---|---|
| 0～1分钟 | 抱离热源，立即用凉水冲烫伤部位（持续冲，不中断） |
| 1～3分钟 | 凉水浸泡被热水浸湿的衣物后轻轻移除；粘住的部位剪开周围，不硬撕 |
| 3～4分钟 | 观察：仅有发红、无渗出 → 无菌纱布轻覆；有水疱/渗出 → 覆纱布后**立即就医** |
| 全程禁止 | 涂黄油、酱油、牙膏；放冰块；摩擦 |
| 判断住院 | 若烫伤在脸/手/足/生殖器/关节，或呈环绕状，或面积≥10% → 直接急诊 |

## Key Takeaways
1. 急症判断清单十条；任何一条命中即启动急救流程（镇定→CPR→拨120→压迫止血）。
2. 中毒不催吐；抽搐侧头不塞物；烧伤只冲凉水不涂任何东西。
3. **任何动物咬伤都要就医**——评估破伤风与狂犬病，伤口大小无关。
4. 烧伤住院五条指征：三度、≥10%体表面积、特殊部位、环绕状、居家无法处理。
5. 异物预防看年龄：4岁前不给整颗坚果和弹性食物，圆形硬食物切成≤1厘米小块。
